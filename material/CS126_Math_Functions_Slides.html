abs() and round()

Code
print(abs(-7), abs(2.5), abs(0))
print(round(3.14159, 2))
print(round(7.6))
print(round(1234, -2))
print(round(2.5), round(3.5))
Output
7 2.5 0
3.14
8
1200
2 4
  • abs(x): distance from zero — always ≥ 0.
  • round(x, n): round to n decimal places.
  • round(x) with no n gives an integer.
  • A negative n rounds to tens, hundreds, …
Exactly halfway (.5), Python rounds to the even number: round(2.5) is 2, round(3.5) is 4. This is called banker's rounding.

Powers: pow() and **

Code
print(pow(2, 3), 2 ** 3)
print(pow(5, 2), pow(2, -1))
print(pow(9, 0.5))
print(pow(2, 3, 5))
Output
8 8
25 0.5
3.0
3
  • pow(a, b) is the same as a ** b: a to the power b.
  • A negative power gives a fraction: 2−1 = 0.5.
  • Power 0.5 is the square root.
  • pow(a, b, m) gives the remainder of ab ÷ m: 8 ÷ 5 leaves 3.
With whole numbers, pow keeps an integer result.

divmod(): Quotient and Remainder Together

Code
print(17 // 5, 17 % 5)
print(divmod(17, 5))
minutes = 125
h, m = divmod(minutes, 60)
print(h, "h", m, "min")
Output
3 2
(3, 2)
2 h 5 min
  • divmod(a, b) returns a tuple: (a // b, a % b).
  • // = how many whole times; % = what is left over.
  • Unpack the tuple into two variables in one line.
Useful for minutes → hours, fils → dinars, items → boxes.

math.sqrt(): Square Root

  • Always returns a float (4.0, not 4).
  • The number must be ≥ 0. A negative number has no real square root → ValueError.
  • "Domain error" means: this input is not allowed for this function.

math.factorial()

Code
import math
print(math.factorial(5))
print(math.factorial(0))
print(math.factorial(10))
Output
120
1
3628800
Errors 
math.factorial(-1)
math.factorial(2.5)
ValueError: factorial() not defined for negative values
TypeError: 'float' object cannot be interpreted as an integer
  • n! = n × (n−1) × … × 1. Example: 5! = 5 × 4 × 3 × 2 × 1 = 120.
  • By definition, 0! = 1.
  • Only whole numbers ≥ 0 are allowed.
Real use: the number of ways to order 5 students in a line is 5! = 120.

math.pi, math.sin(), math.cos()

Code
import math
print(math.pi)
print(math.sin(math.pi / 2), math.cos(0))

angle = math.radians(30)   # 30 degrees
print(math.sin(angle))
print(round(math.sin(angle), 4))
Output
3.141592653589793
1.0 1.0
-1.0
0.49999999999999994
0.5
  • math.pi ≈ 3.14159 — the ratio of a circle's circumference to its diameter.
  • sin and cos use radians, not degrees.
  • 180° = π radians. Convert with math.radians(deg) (and back with math.degrees(rad)).
  • Results are often slightly off (0.49999…) because computers store decimals approximately. Use round to display them.

math.nan: "Not a Number"

Code
import math
x = math.nan
print(x)
print(x + 5, x * 0)
print(x == x)
print(math.isnan(x), math.isnan(3.0))
Output
nan
nan nan
False
True False
  • nan is a special float that means "missing" or "not a valid number" — for example, a sensor reading that failed.
  • Any calculation with nan gives nan.
  • nan is not equal to anything, not even itself!
  • To test for it, use math.isnan(x) — never x == math.nan.

Common Mistakes (1): Importing

Incorrect 
x = math.sqrt(25)
NameError: name 'math' is not defined

Why? The library was never imported.

Correct 
import math
x = math.sqrt(25)
print(x)
5.0
Incorrect 
import math
x = sqrt(25)
NameError: name 'sqrt' is not defined

Why? After import math, the name must start with math.

Correct 
import math
print(math.sqrt(25))
5.0

Worked Example 1: A Roundabout in Kuwait City

Code — a circular garden, radius 12.5 m
import math
r = 12.5
area = math.pi * r ** 2
circumference = 2 * math.pi * r
print("Area:", round(area, 2), "m2")
print("Fence:", round(circumference, 2), "m")
rolls = math.ceil(circumference / 10)
print("Fence rolls of 10 m:", rolls)
Output
Area: 490.87 m2
Fence: 78.54 m
Fence rolls of 10 m: 8

Step by step

  1. Area = π r² ≈ 490.87 m².
  2. Circumference = 2 π r ≈ 78.54 m.
  3. 78.54 ÷ 10 = 7.854 rolls. We cannot buy part of a roll, so ceil rounds up to 8.
round for display; ceil when you must have enough.

Worked Example 2: A School Trip

Code — 47 students, each bus holds 12
import math
students = 47
seats = 12
full, left = divmod(students, seats)
buses = math.ceil(students / seats)
print("Full buses:", full, "Students left:", left)
print("Buses needed:", buses)
print("Empty seats:", buses * seats - students)
trip_minutes = 135
h, m = divmod(trip_minutes, 60)
print("Trip time:", h, "h", m, "min")
Output
Full buses: 3 Students left: 11
Buses needed: 4
Empty seats: 1
Trip time: 2 h 15 min
  1. divmod(47, 12) → (3, 11): 3 full buses and 11 students left.
  2. Those 11 still need a bus, so ceil(47 / 12) = ceil(3.92) = 4.
  3. 4 × 12 − 47 = 1 empty seat.
  4. divmod again turns minutes into hours and minutes.

Worked Example 3: Distance Between Two Points

Code — points on a map grid (km)
import math
home = (2, 3)
school = (8, 11)
x1, y1 = home
x2, y2 = school
dx = abs(x2 - x1)
dy = abs(y2 - y1)
distance = math.sqrt(dx ** 2 + dy ** 2)
print("Straight line:", distance, "km")
print("Along streets:", dx + dy, "km")
Output
Straight line: 10.0 km
Along streets: 14 km
  1. Unpack each tuple into x and y.
  2. abs gives positive differences: 6 and 8.
  3. Pythagoras: √(6² + 8²) = √100 = 10.0.
  4. If you must follow a grid of streets, the distance is 6 + 8 = 14.

What You Should Remember

  1. Built-ins need no import: abs, round, pow, max, min, sum, divmod.
  2. For the rest: import math, then math.name.
  3. round → nearest (.5 to even); ceil → up; floor → down; trunc → toward 0.
  4. math.sqrt and math.pow return floats; divmod returns a tuple.
  5. sin / cos use radians — convert with math.radians.
  6. nan is never equal to anything; test with math.isnan.
  7. Floats are approximate — use round to display and to compare.
