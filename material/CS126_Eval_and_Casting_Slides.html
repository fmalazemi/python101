Why Do We Need to Convert Types?

Code
a = input("First number: ")
b = input("Second number: ")
print(a + b)
print(type(a))
Sample run
First number: 5
Second number: 3
53
<class 'str'>
  • input() always returns text (a string), even when the user types digits.
  • "5" + "3" joins two strings: "53", not 8.
  • Every value in Python has a type, and the type decides what operations do.
To do math with typed numbers, we must change the type of the value. This lecture shows two ways: casting and eval().

What Is Casting?

Casting means creating a value of a new type from an existing value. We call the type's name like a function.

new_value = int("25")

Automatic vs Explicit Conversion

Automatic (implicit) — Python does it

print(5 + 2.0)     # int + float
print(10 / 2)      # / always gives float
print(True + 1)    # True counts as 1
7.0
5.0
2

Python converts only when it is safe: an int becomes a float, never the other way.

Explicit — you do it (casting)

print("Age: " + 19)
TypeError: can only concatenate str (not "int") to str

Python will not mix text and numbers by itself. You must cast:

print("Age: " + str(19))
Age: 19

int(): Convert to a Whole Number

Code
print(int("42"))      # from text
print(int(" 42 "))    # spaces are ignored
print(int(7.9))       # from a float
print(int(-7.9))
print(int(True))      # from a bool
Output
42
42
7
-7
1
  • From a string: the text must be a whole number, like "42".
  • From a float: the decimal part is cut off (not rounded). int(7.9) is 7.
  • From a bool: True → 1, False → 0.
int("7.9") is a ValueError: the text has a dot. Use int(float("7.9")) → 7.
To round instead: round(7.9) → 8.

float(): Convert to a Decimal Number

Code
print(float("3.75"))   # from text
print(float("3"))      # whole number text
print(float(8))        # from an int
print(float(False))
Output
3.75
3.0
8.0
0.0
  • float() accepts text with or without a dot.
  • The result always has a decimal part, even 3.0.
  • It is the best choice for prices, temperatures, and distances.
With input
price = float(input("Price (KD): "))
print(price * 2)

str(): Convert to Text

Code
age = 19
gpa = 3.5
msg = "Age " + str(age) + ", GPA " + str(gpa)
print(msg)
print(str(3) + str(4))
print(len(str(2026)))   # count the digits
Output

34

  • str() works on any value: numbers, bools, lists, …
  • Needed when you join numbers with text using +.
  • Once a number is text, string tools work on it: len, indexing, slicing.
print("Age", 19) does not need str() — commas in print handle any type. str() is needed for +.

Casting Collections: list(), tuple(), set()

Casting with input()

Code
name = input("Name: ")           # text: no cast
age = int(input("Age: "))         # whole number
gpa = float(input("GPA: "))       # decimal number
print(name + " will be " + str(age + 1) + " next year")
print("GPA out of 100:", gpa / 4 * 100)
Sample run
Name: Sara
Age: 20
GPA: 3.6
Sara will be 21 next year
GPA out of 100: 90.0

How int(input("Age: ")) runs

  1. The inner call runs first: input returns "20".
  2. int("20") makes the number 20.
  3. 20 is stored in age.
Choose the cast by what the user should type: text → none, whole number → int, decimal → float.

What Is eval()?

eval(text) reads a string as if it were Python code, calculates it, and returns the value.

x = eval("3 + 4")
print(x, type(x))
print(eval("7 / 2"))
print(type(eval("[1, 2, 3]")))
print(type(eval("(29, 47)")))
print(type(eval("{1, 2, 2}")))
7 <class 'int'>
3.5
<class 'list'>
<class 'tuple'>
<class 'set'>
  • The name comes from evaluate: "work out the value".
  • The string must be a valid Python expression — something that has a value.
  • Casting functions choose the type you ask for. eval decides the type from the text itself.
It is like typing the text directly into Python and seeing the answer.

eval(input()): Reading Numbers

Code
a = eval(input("First number: "))
b = eval(input("Second number: "))
print(a + b)
print(type(a), type(b))
Sample run
First number: 5
Second number: 2.5
7.5
<class 'int'> <class 'float'>
The user can type a whole number or a decimal — eval gives an int or a float to match.

Reading Several Values in One Line

Code
w, h = eval(input("Width, height: "))
print("Area:", w * h)
Sample run
Width, height: 8, 3.5
Area: 28.0
Code
a, b, c = eval(input("Three marks: "))
print("Average:", (a + b + c) / 3)
Sample run
Three marks: 90, 85, 77
Average: 84.0

How it works

  1. The user types 8, 3.5.
  2. eval("8, 3.5") gives the tuple (8, 3.5) — commas make a tuple.
  3. The tuple is unpacked into w and h.
Values must be separated by commas, not spaces. The number of values must match the number of variables, or you get a ValueError.

Casting cannot do this: int("8, 3") is a ValueError.

Reading a List — and Casting the Result

Code
temps = eval(input("Temperatures: "))
print(type(temps), len(temps))
print("Max:", max(temps), "Min:", min(temps))
print("Different values:", len(set(temps)))
print("Fixed copy:", tuple(temps))
Sample run
Temperatures: [44, 46, 48, 46, 47]
<class 'list'> 5
Max: 48 Min: 44
Different values: 4
Fixed copy: (44, 46, 48, 46, 47)
  • The brackets the user types decide the type: [ ] list, ( ) tuple, { } set.
  • After eval builds the list, casting converts it further: set(temps), tuple(temps).
Do not confuse them: list(input()) gives a list of characters:
list("[4, 5]") → ['[', '4', ',', ' ', '5', ']']

Warning: eval() Runs Whatever Is Typed

Code — the user types a function call
x = eval(input("Enter a number: "))
print("You entered:", x)
Sample run
Enter a number: print("I ran your code!")
I ran your code!
You entered: None

The user did not type a number — and Python ran their code anyway.

Why this matters
  • A user could type code that deletes files, reads private data, or crashes the program.
  • Real websites and apps never pass user input to eval.
Rule for this course: eval(input()) is fine for your own practice programs, where you are the user. Otherwise, use casting: int() or float().

Worked Example 1: Petrol Station Receipt

Code
name = input("Customer name: ")
litres = float(input("Litres pumped: "))
price = 0.085                  # KD per litre
total = round(litres * price, 3)
print("Customer: " + name)
print("Litres: " + str(litres))
print("Total: " + str(total) + " KD")
Sample run
Customer name: Ahmad
Litres pumped: 40
Customer: Ahmad
Litres: 40.0
Total: 3.4 KD

Step by step

  1. name stays text — no cast needed.
  2. float("40") → 40.0.
  3. 40.0 × 0.085 = 3.4 (rounded to 3 places for fils).
  4. str() turns the numbers into text so + can join them.

Worked Example 2: Room Area and Flooring Cost

Code
length, width = eval(input("Length, width (m): "))
price = float(input("Price per m² (KD): "))
area = length * width
cost = area * price
print("Area:", area, "m²")
print("Cost:", round(cost, 3), "KD")
Sample run
Length, width (m): 4.5, 3
Price per m² (KD): 6.75
Area: 13.5 m²
Cost: 91.125 KD

Step by step

  1. eval("4.5, 3") → (4.5, 3), unpacked into two variables.
  2. One number only → float() is enough (and safer).
  3. Area = 4.5 × 3 = 13.5.
  4. Cost = 13.5 × 6.75 = 91.125 KD.
Use eval only where casting cannot do the job — here, two values in one line.

Worked Example 3: A Grade Report from a List

Code

print("Different marks: " + str(len(set(marks))))
print("Average: " + str(round(avg, 1)))
print("Average (whole): " + str(int(avg)))
if avg >= 60:
    print("Class passed on average")
else:
    print("Class needs support")
Sample run
Marks as a list: [72, 95, 58, 95, 61]
Students: 5
Different marks: 4
Average: 76.2
Average (whole): 76
Class passed on average
  1. eval builds a real list from the typed text.
  2. set(marks) removes the repeated 95 → 4 different marks.
  3. 381 / 5 = 76.2; int(76.2) → 76.
  4. str() lets us join every number with text.

Think About It

1. Why does int(3.5) work, but int("3.5") fails?
From a float, int just cuts off the decimals. From text, it only accepts the digits of a whole number, and a dot is not allowed.
2. A program reads a phone number like 96551234. Should it cast it to int?
No. We never do math with phone numbers, and a number like 0096551234 would lose its zeros. Keep it as a string.
3. When is eval(input()) better than float(input())?
When the user must type several values, an expression, or a list — and only in a practice program where the input is trusted.

What You Should Remember

  1. input() always returns a string.
  2. Casting makes a new value of another type: int(), float(), str(), bool(), list(), tuple(), set().
  3. int() cuts off decimals; int("3.5") is a ValueError.
  4. Use str() to join numbers with text using +.
  5. bool() is False only for "empty" values: 0, "", [], …
  6. eval(text) calculates text as Python; a, b = eval(input()) reads two values.
  7. eval runs any code: prefer casting, and use eval only with input you trust.
