What Is a Function?

A function is a named block of code that does one job. You give it a name once, then call it by name whenever you need that job done.

You have already used many built-in functions:

print(len("Kuwait"))
print(max(4, 9, 2))
print(round(3.756, 1))
6
9
3.8
Today you will write your own functions, and they work in exactly the same way: a name, brackets, and values inside the brackets.

Defining a Function: The Syntax

def function_name(parameters):
    statement 1
    statement 2
    return value   # optional
def — keyword: "define a function"
function_name — you choose it (same rules as variable names)
( ) — brackets, always needed, even if empty
parameters — names for the input values (can be none)
: — colon, ends the first line
indented body — the code of the function (4 spaces)
Choose names that describe the job, using small letters and underscores: after_discount, rectangle_area, show_menu.

Defining Is Not Running: You Must Call the Function

Code — only a definition
def say_welcome():
    print("Welcome to CS126!")
Output

(nothing is printed)

Defining a function only teaches Python the new name. The body does not run yet.

Code — definition, then two calls
def say_welcome():
    print("Welcome to CS126!")

say_welcome()     # call 1
say_welcome()     # call 2
Output
Welcome to CS126!
Welcome to CS126!
To call a function, write its name followed by brackets: say_welcome(). Each call runs the whole body once.

Several Parameters: Order Matters

Code
def show_item(item, price):
    print(item, "costs", price, "KD")

show_item("Coffee", 1.25)
show_item(0.75, "Water")   # wrong order!
Output
Coffee costs 1.25 KD
0.75 costs Water KD
  • Parameters are separated by commas.
  • Arguments are matched to parameters by position: first to first, second to second.
  • Python does not check the meaning — a wrong order gives a wrong result.
The number of arguments must match the number of parameters:
show_item("Tea") →
TypeError: show_item() missing 1 required positional argument: 'price'

Sending a Value Back: return

Code
def square(n):
    return n * n

result = square(5)
print(result)
print(square(3) + square(4))
Output
25
25
  • return sends a value back to the place of the call.
  • The call square(5) is then replaced by that value.

How result = square(5) works

  1. Python calls square; n gets 5.
  2. n * n is calculated: 25.
  3. return sends 25 back.
  4. The line becomes result = 25.
result = square(5)
result = 25

square(3) + square(4) becomes 9 + 16 = 25.

What Can You Do With a Returned Value?

Code
def rectangle_area(width, height):
    return width * height

a = rectangle_area(4, 3)          # store
print(a)
print(rectangle_area(2, 5))       # print
total = a + rectangle_area(1, 6)  # calculate
print(total)
if rectangle_area(10, 10) > 50:   # compare
    print("Big room")
Output
12
10
18
Big room

A returned value can be used anywhere a value can be used:

  • stored in a variable
  • printed
  • used in a calculation
  • used in a condition
  • given to another function
This is the big advantage of return: the result is not only shown — it can be used again by the rest of the program.

return Ends the Function

Code — return inside if / else
def pass_or_fail(mark):
    if mark >= 60:
        return "Pass"
    else:
        return "Fail"

print(pass_or_fail(75))
print(pass_or_fail(42))
Output
Pass
Fail

A function can have several return lines, but only one of them runs in each call.

Code — lines after return never run
def bigger(a, b):
    if a > b:
        return a
    return b
    print("This never runs")

print(bigger(7, 12))
Output
12
As soon as return runs, the function stops and Python goes back to the call.

print vs return

Prints the result

def add_print(a, b):
    print(a + b)

x = add_print(2, 3)
print("x is", x)
5
x is None

The 5 is shown on the screen, but the program cannot use it: x gets None.

Returns the result

def add_return(a, b):
    return a + b

x = add_return(2, 3)
print("x is", x)
x is 5

Nothing is shown inside the function, but the value 5 is given back and stored in x.

print = show to the person. return = give to the program. If the result will be used later, return it.

Void Functions: Functions That Return Nothing

Code
def print_receipt(item, price):
    print("Item:", item)
    print("Price:", price, "KD")
    print("Thank you!")

print_receipt("Shawarma", 0.75)
value = print_receipt("Juice", 0.5)
print(value)
Output
Item: Shawarma
Price: 0.75 KD
Thank you!
Item: Juice
Price: 0.5 KD
Thank you!
None
  • A void function does a job (usually printing) but has no return value.
  • Python still gives back a special value: None, which means "no value".
  • Call a void function on its own line: print_receipt("Shawarma", 0.75). Storing its result is not useful.
print() itself is a void function: it shows text but returns None.

A plain return with no value also ends a function and gives None.

Returning Several Values

Code
def split_time(minutes):
    hours = minutes // 60
    mins = minutes % 60
    return hours, mins

h, m = split_time(135)
print(h, "hours and", m, "minutes")

t = split_time(90)
print(t, type(t))
Output
2 hours and 15 minutes
(1, 30) <class 'tuple'>
  • Write the values after return, separated by commas.
  • Python puts them in a tuple and returns that one tuple.
  • Unpack the tuple into variables: h, m = split_time(135).
  • Or keep the tuple and use indexes: t[0], t[1].
The number of variables must match the number of returned values:
a, b, c = split_time(90) → ValueError: not enough values to unpack (expected 3, got 2)

Returning Several Values: A Grades Example

Code
def grade_stats(marks):
    lowest = min(marks)
    highest = max(marks)
    average = sum(marks) / len(marks)
    return lowest, highest, average

low, high, avg = grade_stats([72, 95, 58, 88])
print("Lowest:", low)
print("Highest:", high)
print("Average:", avg)
Output
Lowest: 58
Highest: 95
Average: 78.25
  1. The list is copied into the parameter marks.
  2. The function calculates three values with built-in functions.
  3. return sends back the tuple (58, 95, 78.25).
  4. The tuple is unpacked into low, high, avg — in the same order.
One call, three results. Without this, we would need three separate functions.

Common Mistakes (1): Calling the Function

Incorrect 
def say_hi():
    print("Hi!")

say_hi           # no brackets

Output: nothing is printed.

Why? Without ( ), the function is only named, not called.

Correct 
def say_hi():
    print("Hi!")

say_hi()
Hi!
Incorrect 
print(cube(2))

def cube(n):
    return n ** 3
NameError: name 'cube' is not defined

Why? Python reads from top to bottom. At the call, cube is not defined yet.

Correct 
def cube(n):
    return n ** 3

print(cube(2))
8

Common Mistakes (2): print Instead of return

Incorrect 
def add(a, b):
    print(a + b)

total = add(2, 3) * 2
5
TypeError: unsupported operand type(s) for *: 'NoneType' and 'int'

Why? add prints 5 but returns None. Python cannot calculate None * 2.

Correct 
def add(a, b):
    return a + b

total = add(2, 3) * 2
print(total)
10
When you see None or 'NoneType' in an error, check whether the function forgot to return its result.

Common Mistakes (3): Arguments and Variables

Incorrect 
def area(width, height):
    return width * height

print(area(5))
TypeError: area() missing 1 required positional argument: 'height'

Why? The function has 2 parameters but got only 1 argument.

Correct 
def area(width, height):
    return width * height

print(area(5, 2))
10
Incorrect 
def find_tax(price):
    tax = price * 0.15

find_tax(100)
print(tax)
NameError: name 'tax' is not defined

Why? Variables created inside a function exist only inside it. To use a result outside, return it.

Correct 
def find_tax(price):
    return price * 0.15

tax = find_tax(100)
print(tax)
15.0

Worked Example 1: A Discount Calculator

Code
def final_price(price, percent):
    discount = price * percent / 100
    return price - discount

p = float(input("Price (KD): "))
d = float(input("Discount %: "))
result = final_price(p, d)
print("You pay:", result, "KD")
print("You save:", p - result, "KD")
Sample run
Price (KD): 25
Discount %: 20
You pay: 20.0 KD
You save: 5.0 KD

Step by step

  1. The def block is learned, not run.
  2. The user types 25 and 20.
  3. final_price(25.0, 20.0): price = 25.0, percent = 20.0.
  4. discount = 25.0 × 20.0 / 100 = 5.0.
  5. Returns 25.0 − 5.0 = 20.0, stored in result.
  6. Because the value was returned, we can use it again to find the saving.

Worked Example 2: Letter Grade and Report

Code
def letter_grade(mark):          # returns a value
    if mark >= 90:
        return "A"
    elif mark >= 75:
        return "B"
    elif mark >= 60:
        return "C"
    else:
        return "F"

def print_report(name, mark):    # void function
    grade = letter_grade(mark)
    print(name, "-", mark, "-", grade)

print_report("Noor", 93)
print_report("Fahad", 67)
Output
Noor - 93 - A
Fahad - 67 - C
  1. letter_grade calculates, so it returns the letter.
  2. print_report shows a line, so it is a void function.
  3. print_report calls letter_grade — a function can call another function.
  4. For Fahad: 67 is not ≥ 90 or ≥ 75, but it is ≥ 60 → "C".
Each function does one job. Small functions are easier to test and to reuse.

Worked Example 3: Trip Fuel and Cost (Two Return Values)

Code — Kuwait City to Dammam, about 400 km
def trip_fuel(km, km_per_litre, price):
    litres = km / km_per_litre
    cost = litres * price
    return litres, round(cost, 3)

litres, cost = trip_fuel(400, 12.5, 0.085)
print("Fuel needed:", litres, "litres")
print("Fuel cost:", cost, "KD")
Output
Fuel needed: 32.0 litres
Fuel cost: 2.72 KD
  1. Arguments by position: km = 400, km_per_litre = 12.5, price = 0.085.
  2. litres = 400 / 12.5 = 32.0.
  3. cost = 32.0 × 0.085 = 2.72.
  4. return litres, round(cost, 3) sends back (32.0, 2.72).
  5. The tuple is unpacked into two variables outside the function.

Note: the names litres and cost outside the function are different variables from the ones inside — they just have the same names.

Think About It

1. A function prints a result but does not return it. Is that always wrong?
No. If its job is only to show something (a menu, a receipt), a void function is fine. It is a problem when the program needs to use the result later.
2. Why should a function usually return a value instead of printing it?
A returned value can be stored, compared, used in calculations, or printed later — the caller decides. A printed value can only be seen.
3. What does return a, b really return?
One tuple that contains two values: (a, b).

What You Should Remember

  1. A function is a named block of code: define it with def name(parameters): and an indented body.
  2. Defining does not run the code; calling name(arguments) does.
  3. Arguments are copied into parameters by position; their number must match.
  4. return value sends a value back to the call and ends the function.
  5. A void function has no return value; Python gives back None.
  6. return a, b returns a tuple; unpack it with x, y = f(...).
  7. print shows to the person; return gives to the program.
