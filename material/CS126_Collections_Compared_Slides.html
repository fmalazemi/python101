List vs Tuple vs Set vs String

A side-by-side review: similarities, differences, and how to choose
Dr. Fawaz Alazemi

Learning Objectives

By the end of this lecture, you will be able to:

  1. Create a list, a tuple, a set, and a string, including empty and one-item versions.
  2. Name the operations that all four types share.
  3. Explain the three key differences: order, duplicates, and mutability.
  4. Know which operations work only on some types (indexing, slicing, +, methods).
  5. Convert between the four types with list(), tuple(), set(), split(), and join().
  6. Predict the result of == and in for each type.
  7. Choose the best type for a given task, and explain why.

  • Both sides of + must be the same type: [1] + (2,) → TypeError.

Difference 1: Order

Code
l = ["Sun", "Mon", "Tue"]
t = ("Sun", "Mon", "Tue")
print(l[1], t[1])
st = {"Sun", "Mon", "Tue"}
print(len(st))
print(sorted(st))
Output
Mon Mon
3
['Mon', 'Sun', 'Tue']
  • Strings, lists, and tuples remember the order you wrote.
  • A set does not. Printing a set of strings may show a different order each run.
  • Need a fixed order from a set? Use sorted() (alphabetical, not original).
If the order matters (a queue, days of the week, the steps of a recipe), do not use a set.

Difference 2: Duplicates

Code — visits to a café
visits = ["Ali", "Sara", "Ali", "Ali"]
print(len(visits), visits.count("Ali"))
t = tuple(visits)
print(len(t), t.count("Ali"))
st = set(visits)
print(len(st))
print("banana".count("a"), len(set("banana")))
Output
4 3
4 3
2
3 3
  • Lists, tuples, and strings keep every copy — and have count() to count them.
  • A set keeps one copy of each value. Duplicates disappear automatically.
  • len(set(x)) = number of different values.
Need "how many visits?" → keep the list. Need "how many different people?" → use a set.

Methods: Shared and Special

TypeCommon methodsChange the value?
Stringupper, lower, strip, replace, find, split, count, index, startswithNever — return a new value
Listappend, insert, extend, remove, sort, reverse, count, indexMost change the list and return None

count() and index() are shared by string, list, and tuple — the three ordered types.
Sets have no count (every item appears once) and no index (no positions).

Changes the Value, or Returns a New One?

List method: changes the list

nums = [3, 1, 2]
result = nums.sort()
print(result)
print(nums)
None
[1, 2, 3]

sorted(): returns a new list

nums = [3, 1, 2]
new = sorted(nums)
print(new, nums)
[1, 2, 3] [3, 1, 2]

String method: returns a new string

s = "kuwait"
result = s.upper()
print(result)
print(s)
KUWAIT
kuwait
Rule of thumb:
• mutable type (list, set) → methods usually change it; don't save the result.
• immutable type (string, tuple) → methods return a new value; always save it.

Quick Quiz: Which Type?

1. Customers waiting in line at a bank.
List — order matters and people join and leave.
2. The GPS location of Kuwait Towers.
Tuple — two fixed numbers; the order (latitude, longitude) matters.
3. The GCC countries a traveler has visited.
Set — visiting twice still counts once; order does not matter.
4. A course code such as CS126.
String — it is text.
5. Every grade in an exam, to compute the average.
List — two students may have the same grade, and both count.
6. Usernames that are allowed to log in (checked thousands of times).
Set — the fastest for in checks.

Worked Example 1: The Same Data, Four Ways

Code

l = list(s)
t = tuple(s)
st = set(s)
print(len(s), len(l), len(t), len(st))
print(s.count("a"), l.count("a"), t.count("a"))
print(s[0], l[0], t[0])
print("n" in s, "n" in l, "n" in t, "n" in st)
l[0] = "B"
print("".join(l), s)
Output
6 6 6 3
3 3 3
b b b
True True True True
Banana banana
  1. String, list, and tuple keep all 6 characters; the set keeps 3 different ones.
  2. count and indexing work on the three ordered types only.
  3. in works on all four.
  4. Only the list can be changed; join turns it back into a string. s is unchanged.

Worked Example 2: One Student, Four Types

Code
name = "  noor alsabah "        # string
birth = (12, 5, 2006)           # tuple: fixed
grades = [88, 75, 88]           # list: changes
courses = {"CS126", "MATH101"}  # set: unique
name = name.strip().title()
grades.append(92)
courses.add("CS126")
courses.add("ENG110")
day, month, year = birth
print(name, "born in", year)
print(len(grades), sum(grades) / len(grades))
print(len(courses), sorted(courses))
Output
Noor Alsabah born in 2006
4 85.75
3 ['CS126', 'ENG110', 'MATH101']
  • String: the name, cleaned with methods (saved back).
  • Tuple: the birth date never changes; unpacked into 3 variables.
  • List: grades grow, and 88 twice is correct — both count.
  • Set: adding "CS126" again does nothing; each course once.
Good programs pick the right type for each piece of data.

Worked Example 3: From Text to Clean Data and Back

Code
text = "Kuwait,Qatar,Kuwait,Oman,Qatar,Kuwait"
visits = text.split(",")          # list
print(len(visits), visits.count("Kuwait"))
unique = set(visits)              # set
print(len(unique))
ordered = tuple(sorted(unique))   # tuple
print(ordered)
print(" | ".join(ordered))        # string
Output
6 3
3
('Kuwait', 'Oman', 'Qatar')
Kuwait | Oman | Qatar
  1. string → list with split: 6 visits, 3 to Kuwait.
  2. list → set: duplicates removed → 3 countries.
  3. set → sorted list → tuple: a fixed, ordered result.
  4. tuple → string with join for display.
Each conversion uses the strength of a type.

Think About It

1. Strings and tuples are both immutable. What is the main difference between them?
A string holds only characters; a tuple can hold any values (numbers, strings, lists…).
2. Why does a set have no count() or index()?
Every item appears once, so the count is always 0 or 1; and there are no positions, so there is no index.
3. What does this print?
data = [3, 1, 3]
print(len(data), len(tuple(data)))
print(len(set(data)))
print(sorted(set(data)) == [1, 3])

What You Should Remember

  1. String = text (characters), immutable. List = ordered, changeable. Tuple = ordered, fixed. Set = unique, unordered, changeable.
  2. All four: len, in, min, max, sorted.
  3. Ordered types only (string, list, tuple): indexes, slices, +, *, count, index.
  4. Sets only: union, intersection, difference — and no duplicates.
  5. Immutable (string, tuple): build a new value. Mutable (list, set): methods change it in place.
  6. Empty: "", [], (), set(). One-item tuple: (5,).
  7. Choose by asking: text? unique? will it change?
