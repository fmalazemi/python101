Why Learn List Comprehension?

You already know how to build a new list with a loop:

With a for loop (4 lines)

nums = [1, 2, 3, 4]
squares = []
for n in nums:
    squares.append(n * n)
print(squares)
[1, 4, 9, 16]

With a list comprehension (1 line)

nums = [1, 2, 3, 4]
squares = [n * n for n in nums]
print(squares)
[1, 4, 9, 16]
Same result. Shorter, and it reads like English: "n times n, for each n in nums."

What Is a List Comprehension?

A list comprehension is a short way to build a new list from another sequence. It is written inside square brackets [ ].

PartMeaning
ExpressionThe value to put in the new list for each item
Loop variableHolds the current item, as in a for loop
SequenceWhere the items come from: a list, a string, or a range
Condition (optional)Keeps only the items that pass a test
A list comprehension always gives a new list. The original sequence does not change.

The Basic Syntax

[expression for item in sequence]
[ ] — square brackets: the result is a list
expression — what goes into the new list
for … in — the same keywords as a for loop
item — loop variable; you choose the name
sequence — list, string, or range()
No colon and no indentation inside
Read it as: "Give me expression, for each item in sequence."

From a Loop to a Comprehension

Loop with append()

result = []
for x in nums:
    result.append(x * 2)

Comprehension

result = [x * 2 for x in nums]

Three steps

  1. Write the square brackets [ ] — they replace result = [].
  2. Put the expression from append(...) first.
  3. Copy the for x in nums part after it, with no colon.

print(prices_kd)

[2, 5, 1, 3]

The Expression Can Be Almost Anything

Expression typeComprehensionResult
Arithmetic[n + 1 for n in [5, 6, 7]][6, 7, 8]
A function call[len(c) for c in ["UAE", "Oman"]][3, 4]
String joining["Dr. " + n for n in ["Ali", "Mona"]]['Dr. Ali', 'Dr. Mona']
Indexing[w[0] for w in ["Kuwait", "Qatar"]]['K', 'Q']
A comparison[t >= 45 for t in [46, 40]][True, False]
The item itself[x for x in "abc"]['a', 'b', 'c']
Rule: the expression is evaluated once for each item, and each result goes into the new list in order.

Comprehensions with range()

Code
squares = [i * i for i in range(1, 6)]
print(squares)

table7 = [7 * i for i in range(1, 11)]
print(table7)
Output
[1, 4, 9, 16, 25]
[7, 14, 21, 28, 35, 42, 49, 56, 63, 70]

You do not need an existing list — range() provides the numbers.

What will this code print?
evens = [2 * i for i in range(5)]
print(evens)
[0, 2, 4, 6, 8]

range(5) gives 0 to 4. Each is doubled.

Comprehensions with Strings

Over the characters of a string

letters = [ch for ch in "Oman"]
print(letters)
['O', 'm', 'a', 'n']

Over a list of strings

cities = ["Kuwait", "Doha", "Muscat"]
sizes = [len(c) for c in cities]
print(sizes)
[6, 4, 6]
What will this code print?
codes = ["KW", "SA", "QA"]
flags = [c + "-GCC" for c in codes]
print(flags)
['KW-GCC', 'SA-GCC', 'QA-GCC']

The result is always a list, even when the input is a string.

Filtering: Adding an if

[expression for item in sequence if condition]

Only items where the condition is True go into the new list. The if comes at the end.

Loop version
grades = [85, 92, 58, 74, 49]
passed = []
for g in grades:
    if g >= 60:
        passed.append(g)
print(passed)
[85, 92, 74]
Comprehension version
grades = [85, 92, 58, 74, 49]
passed = [g for g in grades if g >= 60]
print(passed)
[85, 92, 74]

The new list can be shorter than the original.

More Filtering Examples

Very hot days in Kuwait (°C)

temps = [46, 48, 44, 50, 47, 43, 49]
hot = [t for t in temps if t >= 48]
print(hot)
[48, 50, 49]

Filter and change at the same time

prices = [3, 12, 7, 20]
sale = [p / 2 for p in prices if p > 10]
print(sale)
[6.0, 10.0]
What will this code print?
word = "Kuwait City"
vowels = [ch for ch in word if ch in "aeiou"]
print(vowels)
['u', 'a', 'i', 'i']

Any logical expression can be the condition, including in, and, or, not.

A New Tool: The Conditional Expression

A conditional expression chooses one of two values in a single line:

value_if_true if condition else value_if_false
if statement (you know this)
mark = 72
if mark >= 60:
    result = "Pass"
else:
    result = "Fail"
print(result)
Conditional expression (same result)
mark = 72
result = "Pass" if mark >= 60 else "Fail"
print(result)
Pass

It always needs both if and else.

Choosing a Value: if … else in the Expression

[A if condition else B for item in sequence]
Code
marks = [72, 55, 60, 91]
results = ["Pass" if m >= 60 else "Fail" for m in marks]
print(results)
Output
['Pass', 'Fail', 'Pass', 'Pass']
  • The if … else is part of the expression, so it comes before for.
  • Every item produces a value, so the new list has the same length as the original.
Filter if → at the end, no else, removes items.
Choose if … else → at the front, keeps every item.

Quick Reference: Three Forms

GoalFormLength of new list
Change every item[expr for x in seq]same as seq
Keep some items[expr for x in seq if cond]same or shorter
Choose a value for every item[A if cond else B for x in seq]same as seq

The same data, three ways

nums = [4, -2, 7, -5]
print([n * 10 for n in nums])
print([n for n in nums if n > 0])
print([n if n > 0 else 0 for n in nums])
[40, -20, 70, -50]
[4, 7]
[4, 0, 7, 0]

Using Comprehensions with len() and sum()

Count items that pass a test

temps = [46, 48, 44, 50, 47, 43, 49]
hot_days = len([t for t in temps if t >= 48])
print("Very hot days:", hot_days)
Very hot days: 3

Add up items that pass a test

bills = [12, 45, 8, 30]   # KD
big_total = sum([b for b in bills if b > 10])
print("Total of big bills:", big_total)
Total of big bills: 87
The comprehension builds a list; len() counts it and sum() adds it up.
What will this code print?
nums = [1, 2, 3, 4, 5, 6]
print(sum([n * n for n in nums if n % 2 == 0]))
56

Even numbers 2, 4, 6 → squares 4, 16, 36 → sum 56.

Two Lists Together: Using range(len(...))

Code — a shopping basket
prices = [1.5, 4, 2.25]    # KD per item
qty = [2, 1, 4]            # quantity
line = [prices[i] * qty[i] for i in range(len(prices))]
print(line)
print("Total:", sum(line), "KD")
Output
[3.0, 4, 9.0]
Total: 16.0 KD
  • i takes the indexes 0, 1, 2.
  • The same i reads both lists, so matching items are multiplied.
  • Both lists must have the same length.
Use this when items in two lists are related by position.

Important Facts

1. The original list does not change

nums = [1, 2, 3]
doubled = [n * 2 for n in nums]
print(nums)
print(doubled)
[1, 2, 3]
[2, 4, 6]

To replace the old list, assign back: nums = [n * 2 for n in nums]

2. The loop variable stays inside

squares = [k * k for k in range(3)]
print(k)
NameError: name 'k' is not defined

A for loop keeps its variable after it ends. A comprehension does not.

3. An empty sequence gives []

[x * 2 for x in []] → []

When Should You Use a Normal Loop?

Good for a comprehension

  • You want a new list.
  • Each new item comes from one simple expression.
  • The whole idea fits easily on one line.
temps_c = [20, 30, 45]
temps_f = [c * 9 / 5 + 32 for c in temps_c]

Better as a normal loop

  • You want to print or do actions, not build a list.
  • Each item needs several steps or elif.
  • The one-liner becomes hard to read.
temps_c = [20, 30, 45]
for c in temps_c:
    print(c, "C")
Comprehensions are a shortcut, not a replacement. If a loop is clearer, use the loop.

Common Mistakes (1): Syntax

Incorrect 
nums = [1, 2, 3]
doubled = [for n in nums: n * 2]

Why? The expression must come first, and there is no colon. This is a SyntaxError.

Correct 
nums = [1, 2, 3]
doubled = [n * 2 for n in nums]
Incorrect 
nums = [1, 2, 3]
doubled = (n * 2 for n in nums)
print(doubled)
<generator object <genexpr> at 0x...>

Why? Round brackets ( ) do not make a list. Use square brackets.

Correct 
nums = [1, 2, 3]
doubled = [n * 2 for n in nums]
print(doubled)

Common Mistakes (2): Where Does the if Go?

Incorrect 
nums = [4, -2, 7]
pos = [n for n in nums if n > 0 else 0]

Why? A filter if at the end cannot have else. SyntaxError.

Correct (keep positives) 
nums = [4, -2, 7]
pos = [n for n in nums if n > 0]
print(pos)
[4, 7]
Incorrect 
nums = [4, -2, 7]
pos = [n if n > 0 for n in nums]

Why? An if at the front must have an else. SyntaxError.

Correct (replace negatives) 
nums = [4, -2, 7]
pos = [n if n > 0 else 0 for n in nums]
print(pos)
[4, 0, 7]

Common Mistakes (3): Using the Result

Incorrect 
# goal: double every price
prices = [1, 2, 3]
[p * 2 for p in prices]
print(prices)
[1, 2, 3]

Why? The new list is created and then lost. It is not stored, and prices does not change.

Correct 
# goal: double every price
prices = [1, 2, 3]
prices = [p * 2 for p in prices]
print(prices)
[2, 4, 6]

Store the new list in a variable — here we replace the old list.

Worked Example 1: Temperature Report

Code — Kuwait temperatures (°C)
temps_c = [20, 30, 45, 50]
temps_f = [c * 9 / 5 + 32 for c in temps_c]
labels = ["Hot" if c >= 40 else "OK" for c in temps_c]
hot_count = len([c for c in temps_c if c >= 40])
print(temps_f)
print(labels)
print("Hot days:", hot_count)
Output
[68.0, 86.0, 113.0, 122.0]
['OK', 'OK', 'Hot', 'Hot']
Hot days: 2

Step by step

  1. Change: each Celsius value becomes Fahrenheit. / gives floats.
  2. Choose: each day gets "Hot" or "OK" — same length as the input.
  3. Keep + count: keep days ≥ 40, then len() counts them.
One line per idea — each line is easy to read.

Think About It

1. Can the result of a comprehension be longer than the original list?
No (with one for). Each item gives at most one value: the same length, or shorter with a filter.
2. Which form keeps the length the same: filter if or if … else?
if … else — every item produces a value. A filter may remove items.
3. What does this print?
words = ["Kuwait", "UAE", "Oman"]
print([w for w in words if len(w) > 3])
['Kuwait', 'Oman']

"UAE" has 3 characters, and 3 > 3 is False.

What You Should Remember

  1. A list comprehension builds a new list in one line: [expression for item in sequence].
  2. It replaces the pattern: empty list → for loop → append().
  3. The sequence can be a list, a string, or a range.
  4. Filter with if at the end (no else) — the list may get shorter.
  5. Choose with A if cond else B at the front — the length stays the same.
  6. The original list does not change. Store the result in a variable.
  7. If a comprehension is hard to read, use a normal loop.
