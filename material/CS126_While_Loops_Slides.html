Why Do We Need Another Loop?

A for loop knows the count

for i in range(5):
    print("Hello")

Runs exactly 5 times. A loop over a list runs once per item.

A for loop works when you know how many times, or which items.

Sometimes we do not know the count

  • You save 150 KD every month. How many months until you have 1000 KD?
  • Keep asking for a grade until the user types a valid one.
  • Keep reading names until the user types quit.
A while loop repeats as long as a condition is True. It stops when the condition becomes False.

What Is a while Loop?

A while loop checks a condition. If it is True, the body runs, then Python checks the condition again.

TermMeaning
ConditionA logical expression that is True or False
Loop bodyThe indented lines that repeat
IterationOne run of the loop body
Loop control variableThe variable the condition checks and the body changes
Everyday example: "While the tea is too hot, wait one minute." You check, wait, check again … and stop when the tea is ready.

The while Loop Syntax

while condition:
    statement(s)
while — keyword that starts the loop
condition — any logical expression, like in if
: — colon ends the header line
statement(s) — the loop body
4 spaces — indentation marks the body
The body must change something so the condition can become False
if runs its body at most once.
while runs its body again and again while the condition is True.

First Example: Counting from 1 to 5

Code
count = 1                # 1. initialize
while count <= 5:        # 2. test
    print(count)
    count = count + 1    # 3. update
print("Done")
Output
1
2
3
4
5
Done

The three parts

  1. Initialize — give the control variable a start value before the loop.
  2. Test — the condition decides whether the body runs.
  3. Update — change the variable inside the body, so the loop moves toward stopping.
When count becomes 6, 6 <= 5 is False. The loop ends and "Done" is printed once.

Infinite Loops

If the condition never becomes False, the loop never stops. This is an infinite loop.

Never stops 
count = 1
while count <= 5:
    print(count)
# no update: count stays 1

Prints 1 forever.
To stop it: press Ctrl + C in the terminal, or the Stop button in your editor.

Is this an infinite loop?
n = 1
while n != 10:
    n = n + 2

Yes. n is 1, 3, 5, 7, 9, 11, … It jumps over 10, so n != 10 is always True.

Safer: while n < 10:

Valid indexes: 0 to len(temps) - 1
Code
temps = [46, 48, 44, 50]
i = 0
while i < len(temps):
    print("Day", i + 1, ":", temps[i])
    i = i + 1
Output
Day 1 : 46
Day 2 : 48
Day 3 : 44
Day 4 : 50
  • i starts at 0, the first index.
  • The test is i < len(temps), so the last index used is 3.
  • i <= len(temps) would try temps[4] → IndexError.
For simply visiting every item, a for loop is easier. while is useful when you may need to stop early (next slide).

Stopping Early: A Compound Condition

Code — find the first day above 50 °C
temps = [46, 48, 44, 51, 47, 52]
i = 0
while i < len(temps) and temps[i] <= 50:
    i = i + 1
if i < len(temps):
    print("First day above 50:", i + 1)
else:
    print("No day above 50")
Output
First day above 50: 4

How it works

  • The loop continues only while both parts are True.
  • It stops at index 3 because 51 <= 50 is False.
  • The if after the loop checks why it stopped.
Order matters. With and, Python stops checking when the left part is False. So temps[i] is never read with an index that is too big.

Reading Input Until a Stop Value

Code
name = input("Enter a name (or quit): ")
while name != "quit":
    print("Welcome,", name)
    name = input("Enter a name (or quit): ")
print("Goodbye")
Sample run
Enter a name (or quit): Sara
Welcome, Sara
Enter a name (or quit): Fahad
Welcome, Fahad
Enter a name (or quit): quit
Goodbye

The sentinel pattern

A sentinel is a special value that means "stop" — here, "quit".

  1. Read the first value before the loop.
  2. Test it in the condition.
  3. Read the next value at the end of the body.
The second input() is the update. Without it, the loop never stops.

Input Validation: Ask Again Until It Is Correct

Code
grade = int(input("Enter grade (0-100): "))
while grade < 0 or grade > 100:
    print("Invalid grade. Try again.")
    grade = int(input("Enter grade (0-100): "))
print("Saved:", grade)
Sample run
Enter grade (0-100): 120
Invalid grade. Try again.
Enter grade (0-100): -5
Invalid grade. Try again.
Enter grade (0-100): 85
Saved: 85
  • The condition describes the bad case: below 0 or above 100.
  • While the input is bad, print a message and ask again.
  • If the first input is already valid, the body runs zero times.
Validation is one of the most common real uses of while.

Common Mistakes (1): Syntax and Indentation

Incorrect 
count = 1
while count <= 3
    print(count)
    count = count + 1

Why? The colon : is missing. Python gives a SyntaxError.

Correct 
count = 1
while count <= 3:
    print(count)
    count = count + 1
Incorrect 
count = 1
while count <= 3:
    print(count)
count = count + 1

Why? The update is not indented, so it is outside the loop. count stays 1 → infinite loop.

Correct 
count = 1
while count <= 3:
    print(count)
    count = count + 1

Common Mistakes (2): Wrong Condition or Update

Incorrect 
# goal: print 1 to 5
i = 1
while i < 5:
    print(i)
    i = i + 1

Why? < stops before 5, so only 1 to 4 are printed.

Correct 
i = 1
while i <= 5:
    print(i)
    i = i + 1
Incorrect 
# goal: count down from 10
n = 10
while n > 0:
    print(n)
    n = n + 1

Why? The update moves the wrong way. n grows forever → infinite loop.

Correct 
n = 10
while n > 0:
    print(n)
    n = n - 1

Common Mistakes (3): Loops with Input

Incorrect 
answer = input("Continue? ")
while answer != "no":
    print("Working...")

Why? Input is read only once. The answer never changes → infinite loop.

Correct 
answer = input("Continue? ")
while answer != "no":
    print("Working...")
    answer = input("Continue? ")
Incorrect 
pin = input("PIN: ")
while pin != 1234:
    pin = input("PIN: ")

Why? input() gives a string. "1234" != 1234 is always True → infinite loop.

Correct 
pin = int(input("PIN: "))
while pin != 1234:
    pin = int(input("PIN: "))

Worked Example 2: ATM Withdrawals

Code — pay requests in order while there is enough money
balance = 500
requests = [100, 150, 80, 200, 50]
i = 0
while i < len(requests) and requests[i] <= balance:
    balance = balance - requests[i]
    print("Paid", requests[i], "KD - balance", balance)
    i = i + 1
print("Requests completed:", i)
Output
Paid 100 KD - balance 400
Paid 150 KD - balance 250
Paid 80 KD - balance 170
Requests completed: 3

Step by step

  1. 100 ≤ 500 → pay; balance 400.
  2. 150 ≤ 400 → pay; balance 250.
  3. 80 ≤ 250 → pay; balance 170.
  4. 200 ≤ 170 is False → the loop stops.
  5. i is 3, the number of paid requests.

The last request (50) is never checked.

Worked Example 3: Guessing Game

Code
secret = 7
guess = int(input("Guess (1-10): "))
tries = 1
while guess != secret:
    if guess < secret:
        print("Too low")
    else:
        print("Too high")
    guess = int(input("Guess (1-10): "))
    tries = tries + 1
print("Correct! Tries:", tries)
Sample run
Guess (1-10): 4
Too low
Guess (1-10): 9
Too high
Guess (1-10): 7
Correct! Tries: 3

Ideas combined

  • The loop repeats until the guess is correct — we cannot know how many tries.
  • if / else inside the body gives a hint.
  • New input at the end of the body is the update.
  • tries is a counter.

Think About It

1. What is the smallest number of times a while body can run?
Zero. If the condition is False at the first check, the body never runs.
2. Can every for loop be written as a while loop?
Yes — use a counter or an index. The reverse is not always easy: "repeat until the user types quit" has no fixed count.
3. What does this print?
k = 1
while k < 100:
    k = k * 2
print(k)
128

k: 1, 2, 4, …, 64, then 128. Now 128 < 100 is False.

What You Should Remember

  1. A while loop repeats its body as long as the condition is True.
  2. Syntax: while condition: then an indented body.
  3. Counting loops need three parts: initialize, test, update.
  4. If the condition never becomes False, you get an infinite loop. Stop it with Ctrl + C.
  5. The body may run zero times if the condition is False at the start.
  6. Use while when you repeat until something happens; use for when you know the items or the count.
  7. With input, read before the loop and again at the end of the body.
