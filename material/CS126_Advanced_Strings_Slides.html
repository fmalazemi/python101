Learning Objectives

By the end of this lecture, you will be able to:

  3. Combine searching with slicing to pull out parts of a string.

  5. Check text with startswith(), endswith(), and the is…() methods.
  6. Build strings with +, +=, *, join(), and f-strings; break them with split().
  7. Chain several methods in one line.

Code

print(s.find("a", 2))      # start at 2
print(s.find("a", 4))      # start at 4
print(s.find("a", 0, 3))   # look in 0..2
print(s.find("n", 0, 2))   # look in 0..1
Output

  • start: where the search begins (default 0).
  • end: where it stops — not included, like a slice.
  • The answer is still an index in the whole string.

Search + Slice: Pulling Out Parts of Text

Code — an email address
email = "sara.ali@ku.edu.kw"
at = email.find("@")
user = email[:at]
domain = email[at + 1:]
country = email[email.rfind(".") + 1:]
print(user)
print(domain)
print(country)
Output
sara.ali
ku.edu.kw
kw

The pattern

  1. Use find / rfind to get a position.
  2. Before it: s[:pos]
  3. After it: s[pos + 1:] — the + 1 skips the separator itself.
  4. Between two positions: s[a + 1:b]
Always think: what if the text is missing? Then find gives −1, and the slice will be wrong without any error.

Code

  • Replaces every match, unless you give a count.
  • count = 1: only the first match.
  • "" as the new text deletes the old text.

To ignore case, convert both sides to the same case first — usually with lower().
  • text.lower() makes a lowercase copy; text is unchanged.
  • Positions in the copy match positions in the original, so you can slice the original: text[11:17] → "KUWAIT".
  • Very useful for user input: "Yes", "YES", and "yes" all match.

Building Strings: +, +=, *

Code

last = "Alazemi"

============

  • + joins two strings (no automatic spaces).
  • s += "x" is short for s = s + "x". It builds a new string and saves it in s.
  • * repeats a string; it is done before +.
  • Numbers must be converted first: str(7.5).

Joining a List into a String: join()

"separator".join(list_of_strings)
Code
gcc = ["Kuwait", "Qatar", "Oman"]
print(", ".join(gcc))
print(" - ".join(gcc))
print("".join(["C", "S", "1", "2", "6"]))
print("/".join(("16", "10", "2026")))
Output
Kuwait, Qatar, Oman
Kuwait - Qatar - Oman
CS126
16/10/2026
  • join belongs to the separator string.
  • The separator goes between items, not at the ends.
  • Works with lists and tuples (and sets — but their order is not fixed).
  • Every item must be a string: "-".join([1, 2]) → TypeError.
Many pieces? join is cleaner than many + signs.

Breaking a String into a List: split()

Code
s = "Kuwait  City   2026"
print(s.split())
print(s.split(" "))

line = "Machboos,3.5,2"
parts = line.split(",")
print(parts)
print(parts[0], float(parts[1]) * int(parts[2]))
Output
['Kuwait', 'City', '2026']
['Kuwait', '', 'City', '', '', '2026']
['Machboos', '3.5', '2']
Machboos 7.0
  • split() with no argument splits on any spaces and ignores extra spaces.
  • split(" ") splits on each single space, so double spaces make empty strings ''.
  • split(",") uses a comma as the separator.
  • The pieces are strings — convert with int() / float() to do math.
split and join are opposites: string → list → string.

f-strings: The Easiest Way to Build Text

Code
name = "Sara"
qty = 3
price = 0.25
print(f"{name} bought {qty} teas.")
print(f"Total: {qty * price} KD")
print(f"Total: {qty * price:.3f} KD")
print(f"{name.upper()} has {len(name)} letters")
Output
Sara bought 3 teas.
Total: 0.75 KD
Total: 0.750 KD
SARA has 4 letters
  • Put f just before the opening quote.
  • Inside { } write any variable or expression — even a method call.
  • No str() needed, no + signs, spaces exactly where you type them.
  • {value:.3f} shows 3 decimal places — perfect for KD and fils.
Compare: name + " bought " + str(qty) + " teas."

Common Mistakes (1): Results and −1

Incorrect 
name = "sara"
name.upper()
print(name)
sara

Why? Strings never change. upper() made a new string, but it was not saved.

Correct 
name = "sara"
name = name.upper()
print(name)
SARA
Incorrect 
email = "sara.ku.edu"
at = email.find("@")
print(email[:at])
sara.ku.ed

Why? No "@" → find gave −1, and email[:-1] silently cut the last letter.

Correct 
email = "sara.ku.edu"
at = email.find("@")
if at == -1:
    print("No @ found")
else:
    print(email[:at])
No @ found

Worked Example 1: Cleaning a Full Name

Code
raw = "  sara mohammad AL-ALI  "
name = raw.strip().title()
first_space = name.find(" ")
last_space = name.rfind(" ")
first = name[:first_space]
last = name[last_space + 1:]
mid = name[first_space + 1]
initials = name[0] + mid + last[0]
print(name)
print(f"{last}, {first}")
print("Initials:", initials)
Output
Sara Mohammad Al-Ali
Al-Ali, Sara
Initials: SMA

Step by step

  1. strip() removes outer spaces; title() fixes the case (also after the dash).
  2. find(" ") → end of the first name.
  3. rfind(" ") → start of the last name, however many middle names there are.
  4. Slices take the parts; indexing takes single letters.
  5. An f-string builds "Last, First".

Worked Example 2: Reading a File Path

Code
path = "C:/Users/ali/report.final.pdf"
slash = path.rfind("/")
folder = path[:slash]
filename = path[slash + 1:]
dot = filename.rfind(".")
ext = filename[dot + 1:].upper()
print("Folder:", folder)
print("File:", filename[:dot])
print("Type:", ext)
print("Is PDF?", filename.lower().endswith(".pdf"))
Output
Folder: C:/Users/ali
File: report.final
Type: PDF
Is PDF? True
  1. rfind("/") finds the last slash (index 12): the folder is before it, the file name after it.
  2. rfind(".") on the file name finds the last dot, so "report.final" stays together.
  3. upper() makes the type easy to read.
  4. lower().endswith() works even for "REPORT.PDF".

Think About It

1. When would s.find(x) and s.rfind(x) give the same number?
When x appears exactly once (or not at all — both give −1).
2. Why does s.replace("a", "b") not change s?
Strings are immutable. replace returns a new string; save it with s = s.replace(...).
3. What does this print?
s = "a-b-c-d"

What You Should Remember

  1. find → first position; rfind → last position; both give −1 if not found.
  2. index / rindex are the same, but raise ValueError if not found.
  3. Search + slice: s[:pos], s[pos + 1:], s[a + 1:b] — check for −1 first.
  4. replace(old, new, count) replaces all matches, or only the first count.
  5. Use lower() on both sides to ignore case.
  6. Build with +, +=, *, "sep".join(list), and f-strings; break with split().
  7. Methods never change the string — always save the result.
