Why Do We Need Lists?

Without a list

grade1 = 85
grade2 = 92
grade3 = 78
grade4 = 95
grade5 = 70

Five variables for five students.
What about a class of 200? A new student means a new variable.

With a list

grades = [85, 92, 78, 95, 70]
print(grades)
[85, 92, 78, 95, 70]
One name, many values. The values stay together and in order.

What Is a List?

A list is an ordered collection of values stored in one variable. Each value is called an item (or element).

gcc = ["Kuwait", "Qatar", "Oman"]
[ ] — square brackets start and end the list
, — commas separate the items
items — any values: numbers, strings, …
order — the items keep the order you wrote
gcc →
"Kuwait"
"Qatar"
"Oman"
Think of a list as a row of boxes under one name, like seats in one row of a classroom.

How Many Items? len()

0

  • len(list) gives the number of items, not characters.
  • "Saudi Arabia" is one item, even though it has 12 characters.
  • Valid indexes: 0 to len − 1.
For a list of 6 items, the last index is 5, not 6.

Error

Is It in the List? in and not in

Code
gcc = ["Kuwait", "Qatar", "Oman"]
print("Qatar" in gcc)
print("Egypt" in gcc)
print("Egypt" not in gcc)
print("kuwait" in gcc)
Output
True
False
True
False
  • x in lst is True if some item equals x.
  • The result is a Boolean, so it can be used in an if.
  • The match must be exact: "kuwait" is not "Kuwait".
  • Types matter: 5 in ["5"] is False.
With a string, in finds parts: "wa" in "Kuwait" is True.
With a list, it checks whole items: "wa" in ["Kuwait"] is False.

Important: Two Names, One List

Code

print(b)
Output

  • A change through either name is seen through both.
This happens because lists can change. You will learn how to make a real copy in the next lecture.

Common Mistakes (1): Counting Positions

Incorrect 
# goal: print the first grade
grades = [85, 92, 78]
print(grades[1])
92

Why? Indexes start at 0. Index 1 is the second item.

Correct 
grades = [85, 92, 78]
print(grades[0])
Incorrect 
# goal: print the last grade
grades = [85, 92, 78]
print(grades[len(grades)])
IndexError: list index out of range

Why? len(grades) is 3, but the last index is 2.

Correct 
grades = [85, 92, 78]
print(grades[len(grades) - 1])
print(grades[-1])

Common Mistakes (2): Writing the List

Incorrect 
cities = ["Kuwait" "Doha", "Oman"]
print(cities)
print(len(cities))
['KuwaitDoha', 'Oman']
2

Why? A missing comma! Python glues two strings that touch. No error appears, so this mistake is hard to see.

Correct 
cities = ["Kuwait", "Doha", "Oman"]
Incorrect 
cities = [Kuwait, Doha]
NameError: name 'Kuwait' is not defined

Why? Without quotes, Python thinks Kuwait is a variable.

Correct 
cities = ["Kuwait", "Doha"]

Common Mistakes (3): Adding and Searching

Incorrect 
# goal: add a 4th grade
grades = [85, 92, 78]
grades[3] = 60
IndexError: list assignment index out of range

Why? lst[i] = x only replaces an item that already exists. It cannot add a new one.

Adding items uses list methods — the topic of the next lecture.
Incorrect 
ids = ["101", "102", "103"]
print(102 in ids)
False

Why? The items are strings; 102 is a number. They are not equal.

Correct 
ids = ["101", "102", "103"]
print("102" in ids)
True

Worked Example 1: A Student Record

Code — [name, age, major, GPA]
student = ["Sara", 20, "CS", 3.4]
print("Name:", student[0])
print("Major:", student[2])
student[3] = 3.6             # new GPA
if student[3] >= 3.5:
    print(student[0], "is on the honor list")
print(student)
Output
Name: Sara
Major: CS
Sara is on the honor list
['Sara', 20, 'CS', 3.6]

Step by step

  1. One list stores four facts about one student.
  2. Each fact has a fixed position: GPA is always at index 3.
  3. student[3] = 3.6 replaces the old GPA.
  4. The if checks the new value: 3.6 ≥ 3.5 is True.
Here the position gives the meaning, so the order of items must stay the same.

Worked Example 2: Weekly Temperatures

Code — Kuwait, Sunday to Saturday (°C)
temps = [44, 46, 48, 45, 47, 94, 43]
temps[5] = 49          # 94 was a typing error
first = temps[0]
last = temps[-1]
middle = temps[len(temps) // 2]
print("Sunday:", first, "Saturday:", last)
print("Wednesday:", middle)
if last < first:
    print("The week ended cooler")
else:
    print("The week ended warmer or the same")
Output
Sunday: 44 Saturday: 43
Wednesday: 45
The week ended cooler
  • Fix the wrong reading with its index.
  • len(temps) // 2 is 7 // 2 = 3, the middle index.
  • Compare items like normal numbers.

Worked Example 3: Who May Enter?

Code — a university lab
admins = ["dr.fawaz", "dr.huda"]
students = ["sara", "ali", "mona"]
blocked = ["ali"]
user = "ali"
if user in admins:
    print("Welcome, administrator")
elif user in students and user not in blocked:
    print("Welcome, student")
else:
    print("Access denied")
Output
Access denied

Step by step for user = "ali"

  1. "ali" in admins → False.
  2. "ali" in students → True, but "ali" not in blocked → False.
  3. True and False → False.
  4. So the else runs.
Lists make rules easy to update: to block a student, change the list, not the if.

Think About It

1. A list has 10 items. What are its first and last positive indexes?
0 and 9. The last index is always len − 1.
2. Why can we write lst[0] = "b" but not word[0] = "b" for a string?
Lists are mutable (can change); strings are immutable.
3. What does this print?
x = [[1, 2], [3, 4, 5]]
print(len(x), len(x[1]), x[-1][-1])
2 3 5

x holds 2 inner lists; the second has 3 items; its last item is 5.

What You Should Remember

  1. A list stores many values, in order, in one variable: [a, b, c].
  2. Indexes start at 0; the last index is len(lst) - 1, or simply -1.
  3. An index that does not exist causes an IndexError.
  4. lst[i] = value replaces an existing item. Lists are mutable; strings are not.
  5. in / not in check whole items, exactly (case and type matter).
  6. == is True only for the same items in the same order.
  7. In a nested list, lst[i][j] means "row i, item j".
