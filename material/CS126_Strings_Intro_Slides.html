What Is a String?

A string is a piece of text: a sequence of characters (letters, digits, spaces, symbols) written inside quotes.

Code
name = "Sara"
city = 'Kuwait City'
course = "CS126"
empty = ""
print(name, city, course)
print(type(name))
Output
Sara Kuwait City CS126
<class 'str'>
  • Single '…' or double "…" quotes both work. Choose one style and be consistent.
  • The quotes are not part of the text; print() does not show them.
  • "" is the empty string: no characters at all.
  • The Python type name is str.
Text is everywhere: names, messages, emails, phone numbers, civil IDs, course codes.

Strings Cannot Be Changed (Immutable)

Error 
word = "cat"
word[0] = "b"
TypeError: 'str' object does not support item assignment

You can read a character with an index, but you cannot replace it.

Build a new string instead 
word = "cat"
word = "b" + word[1:]
print(word)
bat
The old string "cat" is not changed. A new string "bat" is created, and the name word now refers to it.

Worked Example 1: Checking an Email Address

Code
email = "  Sara.Ali@KU.edu.kw "
email = email.strip().lower()
at = email.find("@")
if at <= 0 or email.count("@") != 1:
    print("Invalid email")
else:
    user = email[:at]
    domain = email[at + 1:]
    print("Clean email:", email)
    print("User:", user)
    print("Domain:", domain)
    if domain.endswith(".kw"):
        print("This is a Kuwaiti address")
Output
Clean email: sara.ali@ku.edu.kw
User: sara.ali
Domain: ku.edu.kw
This is a Kuwaiti address
  1. strip().lower(): two methods in a row — remove spaces, then make small letters.
  2. at <= 0 catches a missing @ (−1) or one at the very start (0).
  3. Slices before and after the @ give the two parts.

What You Should Remember

  1. A string is text in quotes; len() counts every character, spaces included.
  2. + joins strings, * repeats them. Use str() / int() to mix with numbers.
  3. Indexes start at 0; s[-1] is the last character.
  4. s[start:stop] — the stop is not included; s[::-1] reverses.
  5. Strings are immutable: methods give back a new string — save it.
  6. in, ==, and < are case-sensitive; use lower() to compare safely.
  7. find() gives −1 when not found; check it before slicing.
