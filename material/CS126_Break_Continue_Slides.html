Loop Control: break and continue

Stopping a loop early, and skipping a round
Dr. Fawaz Alazemi

Learning Objectives

By the end of this lecture, you will be able to:

  1. Use break to stop a loop early.
  2. Use continue to skip the rest of one round and go to the next.
  3. Use both keywords in for loops and while loops.
  4. Write while True loops that end with break.
  5. Explain what break does inside a nested loop.
  6. Trace loops with break and continue, and avoid common mistakes.

Why Do We Need Loop Control?

Code — look for the first mark of 100
marks = [72, 100, 85, 100, 64]
for m in marks:
    print("Checking", m)
    if m == 100:
        print("Found a full mark!")
Output
Checking 72
Checking 100
Found a full mark!
Checking 85
Checking 100
Found a full mark!
Checking 64
  • We wanted the first full mark only.
  • The loop found it in round 2, but it kept going to the end of the list.
  • With a list of 10,000 students, that is a lot of wasted work.
A normal loop always runs to the end. Sometimes we need to stop early, or to skip some items. Python gives us two keywords for this: break and continue.

Two Keywords, Two Jobs

break — stop the loop

Leaves the loop immediately. No more rounds. Python continues with the first line after the loop.

Like: waiting in a queue at a restaurant, then leaving the queue because your friend already bought the food.

continue — skip this round

Stops the current round only, and jumps to the next round of the loop. The loop keeps going.

Like: marking exam papers and skipping a blank paper, then going on to the next one.

The break Statement

for item in sequence:
    # code that runs every round
    if condition:
        break
    # skipped in the round where break runs
# Python continues here after break
  • break is a keyword, written alone on its own line. No brackets, no value.
  • It is almost always inside an if, so the loop stops only when a condition is True.
  • It works the same way in for loops and while loops.

break in a while Loop: while True

Code
while True:
    name = input("Country (or quit): ")
    if name == "quit":
        break
    print("Welcome,", name)
print("Goodbye")
Sample run
Country (or quit): Kuwait
Welcome, Kuwait
Country (or quit): Oman
Welcome, Oman
Country (or quit): quit
Goodbye
  • while True: the condition is always True, so the loop would run forever…
  • …but break gives it an exit from the inside.
  • Useful when the stop decision comes in the middle of the round — here, right after input.
Same program without break
name = input("Country (or quit): ")
while name != "quit":
    print("Welcome,", name)
    name = input("Country (or quit): ")
print("Goodbye")

Both work. The while True version writes input only once.

The continue Statement

for item in sequence:
    if condition:
        continue
    # skipped in this round only
# the loop then goes on to the next item
  • continue is a keyword, written alone on its own line.
  • It skips the rest of the current round and goes back to the top of the loop.
  • In a for loop: the next item is taken. In a while loop: the condition is checked again.
  • The loop does not end; only one round is cut short.

continue: Skipping Absent Students

Code — a mark of 0 means "absent"
marks = [80, 0, 95, 0, 70]
total = 0
count = 0
for m in marks:
    if m == 0:

    total = total + m
    count = count + 1
print("Students present:", count)
print("Average:", total / count)

continue in a while Loop: Update First!

Code — odd numbers from 1 to 9
n = 0
while n < 9:
    n = n + 1           # update FIRST
    if n % 2 == 0:
        continue        # skip even numbers
    print(n)
Output
1
3
5
7
9
In a while loop, continue jumps back to the condition. If the update line (n = n + 1) comes after continue, it is skipped too — and n never changes.
Infinite loop — do not run!
n = 1
while n <= 9:
    if n % 2 == 0:
        continue      # n stays 2 forever
    print(n)
    n = n + 1

This prints 1, then gets stuck at n = 2. A for loop does not have this problem: it moves to the next item by itself.

break in Nested Loops

Code
for row in range(1, 4):
    for col in range(1, 5):
        if col == 3:
            break      # inner loop only
        print(row, col)
    print("End of row", row)
Output
1 1
1 2
End of row 1
2 1
2 2
End of row 2
3 1
3 2
End of row 3
  • break and continue affect only the loop they are directly inside — the innermost one.
  • Here, break stops the col loop when col is 3.
  • The outer row loop is not stopped: it prints "End of row" and starts the next row.
Read the indentation to see which loop a break belongs to.

Do I Need continue? Comparing with if

With continue
for m in [80, 0, 95]:
    if m == 0:
        continue
    print("Mark:", m)
    print("Grade points:", m / 25)
With if only
for m in [80, 0, 95]:
    if m != 0:
        print("Mark:", m)
        print("Grade points:", m / 25)
Output (both)
Mark: 80
Grade points: 3.2
Mark: 95
Grade points: 3.8
  • Any continue can be replaced by an if with the opposite condition.
  • continue is helpful when the main work is long: check the bad cases first, then write the main work without extra indentation.
  • For a short body, a plain if is often clearer.
Choose the version that is easiest to read. Both are correct.

Common Mistakes (1): Position and Indentation

Incorrect 
temps = [44, 47, 51]
for t in temps:
    if t > 50:
        print("Hot:", t)
    break

Output: nothing is printed.

Why? break is not inside the if, so it runs in round 1 and the loop stops at once.

Correct 
temps = [44, 47, 51]
for t in temps:
    if t > 50:
        print("Hot:", t)
        break
Hot: 51
Incorrect 
age = 15
if age < 18:
    break
SyntaxError: 'break' outside loop

Why? break and continue work only inside a loop. An if alone is not a loop.

Correct 
age = 15
if age < 18:
    print("Under 18")
Under 18

Common Mistakes (2): Choosing the Wrong Keyword

Incorrect 
# Goal: add all positive prices
total = 0
for p in [2.5, -1, 4.0, 3.5]:
    if p < 0:
        break
    total = total + p
print(total)
2.5

Why? break ends the loop at -1, so 4.0 and 3.5 are never added.

Correct 
# Skip the negative price, keep going
total = 0
for p in [2.5, -1, 4.0, 3.5]:
    if p < 0:
        continue
    total = total + p
print(total)
10.0
Ask yourself: "When this happens, do I want to stop everything (break) or ignore just this one (continue)?"

Worked Example 1: Searching for a Student ID

Code
ids = [2301, 2315, 2342, 2367, 2388]
target = 2342
found = False
for i in range(len(ids)):
    print("Checking", ids[i])
    if ids[i] == target:
        found = True
        break
if found:
    print("Found at position", i)
else:
    print("Not found")
Output
Checking 2301
Checking 2315
Checking 2342
Found at position 2
  1. found starts as False. It is a flag: a variable that remembers whether something happened.
  2. The loop checks each ID by its index.
  3. At index 2, the ID matches: set found = True, then break.
  4. After break, i still holds 2.
  5. The if after the loop uses the flag to choose the message.

Only 3 of the 5 IDs were checked.

Worked Example 2: Three Password Attempts

Code
password = "kuwait2026"
logged_in = False
for attempt in range(1, 4):
    guess = input("Password: ")
    if guess == password:
        logged_in = True
        break
    print("Wrong. Attempts left:", 3 - attempt)
if logged_in:
    print("Welcome!")
else:
    print("Account locked.")
Sample run
Password: abc123
Wrong. Attempts left: 2
Password: kuwait2026
Welcome!
  1. range(1, 4) allows at most 3 rounds.
  2. Round 1: wrong guess → the message is printed, the loop goes on.
  3. Round 2: correct → logged_in = True, break. Round 3 never happens.
  4. After the loop, the flag decides the message.

If all three guesses are wrong, the loop ends normally, logged_in stays False, and the program prints Account locked.

Think About It

1. A for loop over a list of 8 items has a break. What is the largest number of rounds it can run? The smallest?
At most 8 (if break never runs). At least 1 (if break runs in the first round) — or 0 if the list is empty.
2. Is while True without any break a problem?
Yes. It is an infinite loop: nothing can make it stop.
3. What does continue do if it is the last line of the loop body?
Nothing useful — the round was ending anyway. It can be removed.

What You Should Remember

  1. break ends the whole loop; Python goes to the first line after it.
  2. continue ends the current round; the loop goes on with the next one.
  3. Both work in for and while loops, and are almost always inside an if.
  4. while True + break is a common pattern for reading input until a stop word.
  5. In a while loop, update the variable before continue, or the loop may never end.
  6. In nested loops, they affect only the innermost loop.
  7. Use a flag variable to know after the loop whether break happened.
