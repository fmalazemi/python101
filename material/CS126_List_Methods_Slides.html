Learning Objectives

By the end of this lecture, you will be able to:

  1. Take parts of a list with slicing: lst[start:stop:step].
  2. Use the functions len(), sum(), min(), and max().
  3. Add items with append(), insert(), extend(), and +.
  4. Remove items with remove(), safely.
  5. Reorder a list with sort() and reverse().
  6. Build a string from a list with join().
  7. Know which tools change the list and which give a new value.

Two Kinds of Tools: Functions and Methods

Function: name(list)

grades = [85, 92, 78]
print(len(grades))
print(max(grades))
3
92

The list goes inside the brackets. The function gives back an answer. The list does not change.

Method: list.name()

grades = [85, 92, 78]
grades.append(60)
print(grades)
[85, 92, 78, 60]

A method belongs to the list. Write the list, a dot, then the method name. Most list methods change the list.

Today: slicing and functions first (they never change the list), then methods (they do), then join().

Slicing with a Step: lst[start:stop:step]

Code
nums = [10, 20, 30, 40, 50, 60]
print(nums[::2])     # every 2nd item
print(nums[1::2])    # every 2nd from 1
print(nums[::-1])    # backwards
Output
[10, 30, 50]
[20, 40, 60]
[60, 50, 40, 30, 20, 10]
The step says how far to jump. A negative step walks backwards. [::-1] is a reversed copy.
What will this code print?
nums = [10, 20, 30, 40, 50, 60]
print(nums[4:1:-1])
[50, 40, 30]

Start at index 4 and walk backwards, stopping before index 1.

Smallest and Largest: min() and max()

With numbers

temps = [44, 46, 48, 45, 47, 49, 43]
print(max(temps))
print(min(temps))
49
43

With strings: alphabetical order

cities = ["Muscat", "Doha", "Kuwait"]
print(min(cities))
print(max(cities))
Doha
Muscat
Rules
  • All items must be the same kind: all numbers or all strings. Mixed → TypeError.
  • An empty list → ValueError.
  • For strings, uppercase letters come before lowercase: min(["oman", "Qatar"]) is 'Qatar'.

Combining Functions: Average and Range

sum() is 420 and len() is 5, so the average is 420 / 5 = 84.0.

print(sum(data[1:]))

11

Putting Items in Order: sort()

Code
temps = [46, 44, 49, 45]
temps.sort()
print(temps)
temps.sort(reverse=True)
print(temps)
gcc = ["Qatar", "Bahrain", "Kuwait"]
gcc.sort()
print(gcc)
Output
[44, 45, 46, 49]
[49, 46, 45, 44]
['Bahrain', 'Kuwait', 'Qatar']
  • sort() → smallest to largest (A to Z for strings).
  • sort(reverse=True) → largest to smallest.
  • It changes the list. The old order is lost.
  • Items must be the same kind (all numbers or all strings).
Only lists have sort(). A tuple cannot be changed, so it has no sort() method.

Flipping the Order: reverse() and [::-1]

reverse() changes the list

days = ["Sun", "Mon", "Tue"]
days.reverse()
print(days)
['Tue', 'Mon', 'Sun']

[::-1] makes a new list

days = ["Sun", "Mon", "Tue"]
back = days[::-1]
print(back)
print(days)
['Tue', 'Mon', 'Sun']
['Sun', 'Mon', 'Tue']
What will this code print?
nums = [3, 1, 2]
nums.reverse()
print(nums)
[2, 1, 3]

reverse() only flips the current order. It does not sort. For largest-first, use sort(reverse=True).

From a List to a String: join()

"separator".join(list_of_strings)
Code
countries = ["Kuwait", "Oman", "Qatar"]
print(", ".join(countries))
print(" - ".join(countries))
letters = ["C", "S", "1", "2", "6"]
print("".join(letters))
Output
Kuwait, Oman, Qatar
Kuwait - Oman - Qatar
CS126
  • join() is a string method: the separator comes first.
  • The separator goes between items, not at the ends.
  • "" (empty) glues items with nothing between.
  • The result is a string. The list does not change.
Every item must be a string. ", ".join([1, 2]) → TypeError. Works with a tuple of strings too.

Common Mistakes (1): Saving the Result of a Method

Incorrect 
nums = [3, 1, 2]
nums = nums.sort()
print(nums)
None

Why? sort() changes the list and gives back None. Saving that None loses the list.

Correct 
nums = [3, 1, 2]
nums.sort()
print(nums)
[1, 2, 3]
Incorrect 
cities = ["Kuwait", "Doha"]
cities = cities.append("Muscat")
print(cities)
None

Why? The same problem: append() also gives back None.

Correct 
cities = ["Kuwait", "Doha"]
cities.append("Muscat")
print(cities)
['Kuwait', 'Doha', 'Muscat']

Common Mistakes (2): append vs extend, and remove

Incorrect 
# goal: add two grades
grades = [80, 90]
grades.append([70, 60])
print(grades)
[80, 90, [70, 60]]

Why? append() adds the whole list as one item.

Correct 
grades = [80, 90]
grades.extend([70, 60])
print(grades)
[80, 90, 70, 60]
Incorrect 
cart = ["rice", "tea"]
cart.remove("milk")
ValueError: list.remove(x): x not in list

Why? "milk" is not in the list.

Correct 
cart = ["rice", "tea"]
if "milk" in cart:
    cart.remove("milk")
print(cart)
['rice', 'tea']

Common Mistakes (3): Using join()

Incorrect 
names = ["Ali", "Sara"]
print(names.join(", "))
AttributeError: 'list' object has no attribute 'join'

Why? join() belongs to the separator string, not the list.

Correct 
names = ["Ali", "Sara"]
print(", ".join(names))
Ali, Sara
Incorrect 
date = [12, 10, 2026]
print("/".join(date))
TypeError: sequence item 0: expected str instance, int found

Why? The items are numbers. join() needs strings.

Correct 
date = ["12", "10", "2026"]
print("/".join(date))
12/10/2026

Worked Example 1: Grade Report

Code
scores = [72, 95, 58, 88, 61, 79]
scores.sort(reverse=True)
print("Sorted:", scores)
print("Top 3:", scores[:3])
print("Highest:", max(scores), "Lowest:", min(scores))
print("Average:", sum(scores) / len(scores))
Output
Sorted: [95, 88, 79, 72, 61, 58]
Top 3: [95, 88, 79]
Highest: 95 Lowest: 58
Average: 75.5

Step by step

  1. sort(reverse=True) puts the highest score first.
  2. Because the list is sorted, scores[:3] is the top three.
  3. max() and min() do not need a sorted list, but they agree with it.
  4. sum() is 453 and len() is 6 → 453 / 6 = 75.5.

Worked Example 3: Planning a Trip

Code
route = ["Kuwait", "Dubai"]
route.insert(1, "Doha")       # add a stopover
back = route[::-1]            # the return route
trip = route + back[1:]       # skip Dubai twice
print(" -> ".join(route))
print(" -> ".join(trip))
print("Stops:", len(trip))
Output
Kuwait -> Doha -> Dubai
Kuwait -> Doha -> Dubai -> Doha -> Kuwait
Stops: 5

Step by step

  1. insert(1, ...) puts Doha between Kuwait and Dubai.
  2. route[::-1] is a reversed copy: Dubai, Doha, Kuwait. route is unchanged.
  3. back[1:] drops the first Dubai.
  4. + joins both parts into a new list.
  5. join() turns each list into one readable string.

Think About It

1. What is the difference between nums.reverse() and nums[::-1]?
reverse() changes nums and gives None. [::-1] gives a new reversed list and leaves nums unchanged.
2. Why does sum(["1", "2"]) fail, but "".join(["1", "2"]) works?
sum() adds numbers. join() glues strings, giving "12".
3. What does this print?
a = [5, 2, 9]
b = a[:]
b.sort()
print(a, b)
[5, 2, 9] [2, 5, 9]

a[:] is a copy. Sorting the copy does not change a.

What You Should Remember

  1. lst[start:stop:step] gives a new list; stop is not included; [::-1] reverses.
  2. len(), sum(), min(), max() give back a value and do not change the list.
  3. append(x) adds one item; extend(other) adds many; insert(i, x) adds at a position.
  4. a + b makes a new list; a.extend(b) changes a.
  5. remove(x) deletes the first x — check with if x in lst first.
  6. Methods that change a list return None: never write lst = lst.sort().
  7. "sep".join(list) makes a string, and every item must be a string.
