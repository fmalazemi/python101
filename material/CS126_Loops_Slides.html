Why Do We Need Loops?

Without a loop

grades = [85, 92, 78, 95]
print(grades[0])
print(grades[1])
print(grades[2])
print(grades[3])

One print per grade.
What if the class has 200 students?

With a loop

grades = [85, 92, 78, 95]
for grade in grades:
    print(grade)
Output
85
92
78
95
The same 3 lines work for 4 grades or 4,000 grades.

What Is a Loop?

A loop repeats a block of code. A for loop repeats the block once for each item in a sequence.

TermMeaning
SequenceA group of values in order: a list, a string, or a range
Loop variableA variable that holds the current item
Loop bodyThe indented lines that repeat
IterationOne run of the loop body (one "round")
Everyday example: a cashier scans each item in your basket. Same action, repeated for every item, then stop.

The for Loop Syntax

for item in sequence:
    statement(s)
for … in — keywords; always written like this
item — loop variable; you choose the name
sequence — list, string, or range()
: — colon ends the header line
statement(s) — the loop body
4 spaces — indentation marks the body
Same rules as if: a colon, then an indented block. The body ends when the indentation ends.

First Example: Looping Over a List

Code
countries = ["Kuwait", "Qatar", "Oman"]
for country in countries:
    print("Hello from", country)
print("Done!")
Output
Hello from Kuwait
Hello from Qatar
Hello from Oman
Done!

What happens

  1. country gets "Kuwait"; the body runs.
  2. country gets "Qatar"; the body runs.
  3. country gets "Oman"; the body runs.
  4. No items left. The loop ends.
  5. print("Done!") runs once, because it is not indented.

Pattern 1: Adding Up (the Accumulator)

Code — shopping prices in KD
prices = [1.25, 0.75, 2.5, 0.5]
total = 0                 # start at zero
for price in prices:
    total = total + price # add each price
print("Total:", total, "KD")
Output
Total: 5.0 KD
An accumulator is a variable that collects a result as the loop runs. Create it before the loop.

Pattern 2: Counting with if

Code — Kuwait temperatures (°C) for one week in July
temps = [46, 48, 44, 50, 47, 43, 49]
hot_days = 0
for t in temps:
    if t >= 48:
        hot_days = hot_days + 1
print("Very hot days:", hot_days)
Output
Very hot days: 3

How it works

  • hot_days is a counter. It starts at 0.
  • The if is inside the loop, so it checks every temperature.
  • Only 48, 50, and 49 pass the test → the counter goes up 3 times.
  • The print is after the loop, so it shows the final count once.
Counter: add 1. Accumulator: add the value.

Pattern 4: Building a New List or String

Keep only passing grades

grades = [85, 92, 58, 74, 49]
passed = []               # empty list
for g in grades:
    if g >= 60:
        passed.append(g)
print(passed)
[85, 92, 74]

Reverse a string

word = "CS126"
result = ""               # empty string
for ch in word:
    result = ch + result
print(result)
621SC

Each new character goes to the front: "C" → "SC" → "1SC" → "21SC" → "621SC"

A Loop Inside a Loop (Nested Loops)

Code — a café menu
sizes = ["Small", "Large"]
drinks = ["Tea", "Coffee", "Karak"]
for size in sizes:
    for drink in drinks:
        print(size, drink)
Output
Small Tea
Small Coffee
Small Karak
Large Tea
Large Coffee
Large Karak

Rule

For each item of the outer loop, the inner loop runs completely.

Outer sizeInner drink takes
"Small"Tea, Coffee, Karak
"Large"Tea, Coffee, Karak
Total lines printed = 2 × 3 = 6.

Common Mistakes (1): Syntax

Incorrect 
for g in grades
    print(g)

Why? The colon : is missing. Python gives a SyntaxError.

Correct 
grades = [85, 92]
for g in grades:
    print(g)
Incorrect 
for g in grades:
print(g)

Why? The body is not indented. Python gives an IndentationError.

Correct 
grades = [85, 92]
for g in grades:
    print(g)

Common Mistakes (2): Logic

Incorrect 
prices = [3, 5, 2]
for p in prices:
    total = 0
    total = total + p
print(total)

Why? total is reset to 0 in every iteration. It prints 2, not 10.

Correct 
prices = [3, 5, 2]
total = 0
for p in prices:
    total = total + p
print(total)
Incorrect 
# goal: print 1 to 5
for i in range(1, 5):
    print(i)

Why? The stop value is not included. This prints only 1 to 4.

Correct 
# goal: print 1 to 5
for i in range(1, 6):
    print(i)

Common Mistakes (3): Changing a List in a Loop

Incorrect 
# goal: double every price
prices = [1, 2, 3]
for p in prices:
    p = p * 2
print(prices)
[1, 2, 3]

Why? p is only a copy of the current value. Changing p does not change the list.

Correct 
# goal: double every price
prices = [1, 2, 3]
for i in range(len(prices)):
    prices[i] = prices[i] * 2
print(prices)
[2, 4, 6]

Use the index to change the item stored in the list.

Worked Example 1: Class Average

Code
grades = [85, 92, 78, 95, 70]
total = 0
for g in grades:
    total = total + g
average = total / len(grades)
print("Total:", total)
print("Average:", average)
Output
Total: 420
Average: 84.0

Step by step

  1. total starts at 0.
  2. The loop adds each grade:
    85 → 177 → 255 → 350 → 420.
  3. After the loop, len(grades) is 5.
  4. 420 / 5 gives 84.0 (division / always gives a float).
  5. Both print lines run once, after the loop.
The average is calculated after the loop, when the total is complete.

Worked Example 2: Counting Vowels

Code
city = "Kuwait City"
vowels = "aeiouAEIOU"
count = 0
for ch in city:
    if ch in vowels:
        count = count + 1
print("Vowels:", count)
Output
Vowels: 4

Step by step

  1. The loop visits all 11 characters, including the space.
  2. ch in vowels is True for u, a, i, i.
  3. So count goes up 4 times.
Two meanings of in:
for ch in city: → "take each item"
if ch in vowels: → "is it inside?" (True/False)

Worked Example 3: Mobile Data Package

Code — daily data use (GB), package limit 10 GB
usage = [1.5, 2, 0.5, 3, 1, 2.5, 1]
limit = 10
total = 0
for i in range(len(usage)):
    total = total + usage[i]
    if total > limit:
        print("Day", i + 1, "total", total, "- over!")
    else:
        print("Day", i + 1, "total", total)
Output
Day 1 total 1.5
Day 2 total 3.5
Day 3 total 4.0
Day 4 total 7.0
Day 5 total 8.0
Day 6 total 10.5 - over!
Day 7 total 11.5 - over!

Ideas combined

  • range(len(usage)) gives indexes 0 to 6.
  • i + 1 turns index 0 into "Day 1".
  • The accumulator total grows each day.
  • if / else inside the loop checks the total every day.

Think About It

1. How many times does this loop run?
for i in range(2, 8, 2):
3 times: i is 2, 4, then 6. (8 is not included.)
2. Can a for loop run zero times?
Yes. If the sequence is empty — like [], "", or range(5, 2) — the body never runs.
3. What does this print?
n = 0
for ch in "Doha":
    n = n + 1
print(n)
4

It counts characters — the same as len("Doha").

What You Should Remember

  1. A for loop runs its body once for each item in a sequence.
  2. Syntax: for item in sequence: then an indented body.
  3. You can loop over a list (items), a string (characters), or a range (numbers).
  4. range(start, stop, step) never includes the stop value.
  5. Use range(len(lst)) when you need the index or want to change list items.
  6. Create accumulators and counters before the loop; print results after it.
  7. Put an if inside the loop to test every item.
