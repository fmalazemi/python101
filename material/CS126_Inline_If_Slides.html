Why Do We Need an Inline if?

Very often, an if / else only decides which value to store:

Regular if / else (4 lines)

mark = 72
if mark >= 60:
    result = "Pass"
else:
    result = "Fail"
print(result)
Pass

Inline if (1 line)

mark = 72
result = "Pass" if mark >= 60 else "Fail"
print(result)
Pass
Same result. It reads like English: "result is Pass if the mark is at least 60, else Fail."

What Is an Inline if?

An inline if chooses one of two values based on a condition. Its official name is a conditional expression.

TermMeaning
ExpressionCode that produces a value, like 3 + 4 or len("abc")
StatementCode that does an action, like x = 5 or a regular if block
Conditional expressionAn expression whose value depends on a condition
A regular if is a statement: it decides which lines run.
An inline if is an expression: it decides which value you get.

Everyday example: "Take an umbrella if it rains, else take sunglasses." — one choice between two things.

The Syntax

value_if_true if condition else value_if_false
value_if_true — the result when the condition is True
if — keyword
condition — any logical expression
else — keyword, always required
value_if_false — the result when it is False
No colons, no indentation, one line
The order is different from a regular if: the True value comes first, then the condition, then the False value.

First Example: Even or Odd

Code
n = 7
kind = "even" if n % 2 == 0 else "odd"
print(n, "is", kind)

n = 10
kind = "even" if n % 2 == 0 else "odd"
print(n, "is", kind)
Output
7 is odd
10 is even

Step by step (n = 7)

  1. Python checks the condition 7 % 2 == 0.
  2. 7 % 2 is 1, so the condition is False.
  3. The expression gives the value after else: "odd".
  4. kind stores "odd".
For n = 10, the condition is True, so kind gets "even".

How Python Evaluates an Inline if

Only one side runs — useful for safety

total = 90
count = 0
avg = total / count if count != 0 else 0
print(avg)
0

Because count != 0 is False, Python never calculates total / count, so there is no ZeroDivisionError.

What Will This Code Print?

Question 1

You can use the inline if directly inside print().

Question 2

This gives the absolute value (distance from zero).

Question 3

b = 9

A very common use: choose the larger of two values.

Converting Between the Two Forms

if age >= 18:
    status = "Adult"
else:
    status = "Minor"
status = "Adult" if age >= 18 else "Minor"

Recipe

  1. Check: both branches assign to the same variable.
  2. Write the variable and =.
  3. Write the True value, then if and the condition.
  4. Write else and the False value.
  5. Remove the colons and the indentation.
If the two branches do different things (different variables, several lines, printing), keep the regular if.

Inline if with Numbers

Code — a 10% member discount (KD)
price = 20
member = True
discount = price * 0.1 if member else 0
total = price - discount
print("Discount:", discount)
print("Total:", total, "KD")
Output
Discount: 2.0
Total: 18.0 KD

Use brackets inside bigger expressions

price = 20
member = False
total = price - (2 if member else 0)
print(total)
20
The inline if has very low priority. When it is part of a bigger calculation, put it in brackets so Python knows where it starts and ends.

Inline if with Strings

Code
ch = "e"
print("vowel" if ch in "aeiou" else "consonant")

name = "  "
shown = name.strip() if name.strip() != "" else "Guest"
print("Welcome,", shown)

count = 1
print(str(count) + " item" + ("" if count == 1 else "s"))
count = 3
print(str(count) + " item" + ("" if count == 1 else "s"))
Output
vowel
Welcome, Guest
1 item
3 items
  • Any condition works: in, ==, string methods…
  • Choose a default when text is empty.
  • Add "s" only when needed — note the brackets around the inline if.

Inline if with Lists, Tuples, and Sets

Code
cart = []
print("Empty cart" if len(cart) == 0 else "Ready to pay")

weekend = ("Fri", "Sat")
day = "Sat"
print("Day off" if day in weekend else "Work day")

allowed = {"sara", "ali"}
user = "fahad"
print("Welcome" if user in allowed else "Access denied")

temps = [44, 46, 49]
print("Warmer" if temps[-1] > temps[0] else "Not warmer")
Output
Empty cart
Day off
Access denied
Warmer
Everything you know about conditions works here: len(), in, indexes, comparisons.

Combining Conditions with and, or, not

Code — cinema ticket price (KD)
age = 15
student = False
price = 2 if age < 12 or student else 3.5
print("Ticket:", price, "KD")

gpa = 3.7
credits = 40
honor = "Yes" if gpa >= 3.5 and credits >= 30 else "No"
print("Honor list:", honor)

blocked = False
print("Login OK" if not blocked else "Blocked")
Output
Ticket: 3.5 KD
Honor list: Yes
Login OK
  • The whole condition between if and else is evaluated first.
  • 15 < 12 or False is False, so the price is 3.5.
  • For a long condition, store it in a variable first: ok = gpa >= 3.5 and credits >= 30.

Three Rules of the Inline if

1. else is always required

result = "Pass" if mark >= 60
SyntaxError: expected 'else' after 'if' expression

An expression must always produce a value — even when the condition is False.

2. Only one value on each side

No colons, no extra lines, no x = … inside it.

3. Use it for values, not for actions

mark = 72
print("Pass") if mark >= 60 else print("Fail")
Pass

This runs, but it is poor style: the inline if is used only to choose an action.

mark = 72
print("Pass" if mark >= 60 else "Fail")
Pass

Better: choose the value, and call print() once.

Inline else if: More Than Two Choices

A regular if uses elif for extra choices. The inline form puts another inline if after else.

Regular if / elif / else
temp = 38
if temp >= 45:
    level = "Very hot"
elif temp >= 30:
    level = "Hot"
else:
    level = "Mild"
print(level)
Hot
Inline else if (chained)
temp = 38
level = ("Very hot" if temp >= 45
         else "Hot" if temp >= 30
         else "Mild")
print(level)
Hot
The pattern: A if c1 else B if c2 else C. Brackets let you split it over several lines so it is easier to read.

How a Chained Inline if Is Evaluated

"Very hot" if temp >= 45 else ( "Hot" if temp >= 30 else "Mild" )
temp>= 45?>= 30?Result
48Truenot checked"Very hot"
38FalseTrue"Hot"
22FalseFalse"Mild"
  1. Check the first condition. If True → done.
  2. If False → move to the part after else, which is another inline if.
  3. Check the second condition, and so on.
  4. The last else is the value when nothing matched.
Exactly like if / elif / else: conditions are checked from left to right, and the first True one wins.

Example: Letter Grades

Code
mark = 85
letter = ("A" if mark >= 90 else
          "B" if mark >= 80 else
          "C" if mark >= 70 else
          "D" if mark >= 60 else
          "F")
print("Mark", mark, "→ grade", letter)
Output
Mark 85 → grade B
What is the grade for mark = 60? And for 59?
D for 60 (the first True condition is 60 >= 60), and F for 59 (no condition is True).
This works, but five choices on one expression is close to the limit. Many programmers would use a regular if / elif here. Choose what is easiest to read.

When Should You Use an Inline if?

Good for an inline if

  • You are choosing one value from two (or three) options.
  • Both values are short and simple.
  • The result goes into a variable, a print(), or a calculation.
fee = 0 if total >= 20 else 1.5

Better as a regular if

  • Each branch needs several lines.
  • The branches do different actions (change different variables, print different things).
  • There are many choices, or the condition is very long.
if balance < amount:
    print("Not enough money")
else:
    balance = balance - amount
    print("Paid")
Goal: code that a classmate understands in one reading. Short is good; clear is better.

Common Mistakes (1): Syntax

Incorrect 
mark = 72
result = "Pass" if mark >= 60
SyntaxError: expected 'else' after 'if' expression

Why? The inline if must have an else value.

Correct 
mark = 72
result = "Pass" if mark >= 60 else "Fail"
Incorrect 
mark = 72
result = if mark >= 60 "Pass" else "Fail"
SyntaxError: invalid syntax

Why? Wrong order. The True value comes before if.

Correct 
mark = 72
result = "Pass" if mark >= 60 else "Fail"

Common Mistakes (2): Missing Brackets

Incorrect 
cost = 50
msg = "Level: " + "high" if cost > 100 else "low"
print(msg)
low

Why? Python reads it as ("Level: " + "high") if … else "low". The "Level: " part is lost in the False case.

Correct 
cost = 50
msg = "Level: " + ("high" if cost > 100 else "low")
print(msg)
Level: low
Incorrect 
# goal: members pay 2 KD less
price = 10
member = False
total = price - 2 if member else 0
print(total)
0

Why? It means (price - 2) if member else 0. Non-members pay nothing!

Correct 
price = 10
member = False
total = price - (2 if member else 0)
print(total)
10

Common Mistakes (3): Order of Conditions

Incorrect 
mark = 95
letter = ("C" if mark >= 70 else
          "B" if mark >= 80 else
          "A" if mark >= 90 else "F")
print(letter)
C

Why? The first True condition wins. 95 >= 70 is True, so the other checks never happen.

Correct — strictest condition first 
mark = 95
letter = ("A" if mark >= 90 else
          "B" if mark >= 80 else
          "C" if mark >= 70 else "F")
print(letter)
A
The same rule applies to if / elif: when ranges overlap, check the narrowest one first.

Worked Example 1: Online Order (KD)

Code
subtotal = 17.5
member = True
shipping = 0 if subtotal >= 20 or member else 1.5
discount = subtotal * 0.05 if member else 0
total = subtotal + shipping - discount
print("Shipping:", shipping)
print("Discount:", discount)
print("Total:", total, "KD")
print("Free shipping!" if shipping == 0 else "")
Output
Shipping: 0
Discount: 0.875
Total: 16.625 KD
Free shipping!

Step by step

  1. 17.5 >= 20 is False, but member is True → shipping is 0.
  2. Member → discount is 17.5 × 0.05 = 0.875.
  3. Total = 17.5 + 0 − 0.875 = 16.625.
  4. Shipping is 0 → the message is printed.
Each inline if decides one value. Then normal arithmetic uses them.

Worked Example 2: Electricity Bill with Tiers

Code — price per kWh depends on usage (example rates)
kwh = 2500
rate_fils = (3 if kwh <= 1000 else
             5 if kwh <= 3000 else
             10)
bill = kwh * rate_fils / 1000
level = "low" if bill < 10 else "high"
print("Rate:", rate_fils, "fils per kWh")
print("Bill:", bill, "KD")
print("Usage level:", level)
Output
Rate: 5 fils per kWh
Bill: 12.5 KD
Usage level: high

Step by step

  1. 2500 <= 1000 → False.
  2. 2500 <= 3000 → True → rate is 5.
  3. 2500 × 5 = 12500 fils = 12.5 KD.
  4. 12.5 < 10 → False → "high".

The rates are simple examples, not official prices.

Worked Example 3: Weekly Temperature Summary

Code — Kuwait, Sunday to Saturday (°C)
temps = [44, 46, 48, 45, 47, 49, 43]
first = temps[0]
last = temps[-1]
trend = ("warmer" if last > first else
         "cooler" if last < first else
         "the same")
hot_week = "Yes" if 49 in temps or 50 in temps else "No"
print("The week ended", trend)
print("Reached 49 or 50:", hot_week)
print(len(temps), "day" if len(temps) == 1 else "days")
Output
The week ended cooler
Reached 49 or 50: Yes
7 days
  1. 43 > 44 is False; 43 < 44 is True → "cooler".
  2. 49 in temps is True → "Yes" (the or part is not needed).
  3. The list has 7 items → "days".
An inline if works with list indexes, in, and len() — anything that gives True or False.

Think About It

1. Why must an inline if always have an else, while a regular if does not?
An inline if is an expression: it must always give a value. A regular if is a statement: if the condition is False, it can simply do nothing.
2. In A if c1 else B if c2 else C, when is c2 checked?
Only when c1 is False — just like an elif.
3. What does this print?
x = 0
print(10 / x if x != 0 else "cannot divide")
print("zero" if x == 0 else
      "positive" if x > 0 else "negative")
cannot divide
zero

10 / x is never calculated, so there is no error.

What You Should Remember

  1. An inline if chooses a value: A if condition else B.
  2. The True value comes first; the else part is always required.
  3. Only one of the two values is calculated.
  4. Inline else if: A if c1 else B if c2 else C — checked left to right; the first True wins.
  5. Put the inline if in brackets when it is part of a bigger expression (+, -, …).
  6. Use it for short choices between values, not for actions or multi-line branches.
  7. If it becomes hard to read, use a regular if / elif / else.
